# 使用指南

SPA 使用 hash 路由（`#/library`、`#/gallery/7`、…），浏览器刷新与前进/后退无需服务器往返。

## 画廊库（`#/library`）

- 按标题搜索、按分类过滤、分页浏览索引的画廊。
- 点击封面进入画廊详情页。
- **扫描库**触发文件系统扫描：新归档入库，缺失的画廊被标记为已删除（软删除，目录恢复后重新扫描可找回）。

## 画廊详情（`#/gallery/<id>`）

- 展示元数据（大小、自适应单位）、标签与页面缩略图。
- **开始阅读**打开阅读器（定位到上次阅读位置）。
- **同步标签**：从 ExHentai 拉取该画廊标签/元数据；收藏夹已缓存时直接复用缓存（免网络）。
- 画廊属于哪些收藏夹会以徽标显示；属于收藏夹的画廊有**取消收藏**按钮。

## 阅读器（`#/reader/<id>/<page>`）

- 逐页流式加载。用 **←/→ 方向键**、**空格**或**点击图片**翻页。
- **翻过最后一页自动跳转下一画廊**。
- 预加载后三页，翻页即时。
- 进度条显示 `页 / 总页 · 大小`（自适应 B/KB/MB/GB）。
- 阅读位置自动保存。

## 标签（`#/tags`）

- 搜索本地标签体系并查看使用次数；用顶部分组筛选（全部 / 标签 / 作者 / 角色 / 原作 / 社团 / 女性 / 男性 / 语言 / 分类）。
- **翻页时顶部的分组筛选条保持不变**。
- 中文界面下标签显示翻译；多值标签（`A | B`）只显示翻译的部分（未翻译的英文别名自动隐藏）。
- 结果每页最多 500 条。

## 下载页（`#/downloads`）

- 列出下载任务及其状态（等待 / 下载中 / 成功 / 失败 / 已取消），可按状态筛选。
- 活动任务显示**实时进度条**（`当前/总` + 百分比），列表每 2 秒自动刷新。
- **重试可续传**：仅补下缺失/失败的页，已落盘页面跳过。
- 等待/下载中可**取消**；失败/取消/成功可**重试**（单个或勾选批量）。
- 配置 Telegram 后，下载成功/失败、扫描完成会收到通知。

## 日志页（`#/logs`）

统一展示后台任务（库扫描、标签同步、缩略图生成、收藏元数据同步），分为两区：

- **进行中**：每行 = 开始时间 · 任务名 · `进行中 · done/total` · 进度条 · 描述 · **取消**按钮；多任务可并排多行。
- **已完成**：开始时间 · 任务名 · 状态徽标（成功/失败/已取消）· 描述与原因 · **耗时** · 完成时间；已完成任务不再显示进度条。

页面每 2 秒自动刷新。设置里的「立即同步标签 / 立即生成 / 立即更新翻译」触发后也会在此留痕。

## 收藏夹（`#/favorites`）

- 列出十个 ExHentai 收藏文件夹：启用开关、模式（增量下载 / 仅监控 / 强制下载）与轮询间隔；**保存**一次写入。
- **同步收藏夹名称**从 ExHentai 拉取文件夹名。
- **立即检查**扫描该文件夹；**立即检查所有**一次检查全部。
- 每个文件夹显示云端/本地数量与大小；检查进行时名称旁出现**进度环**。
- 每次检查把完整元数据（标题、标签、分类、发布时间、大小）缓存进数据库，并把最新元数据**自动应用**到本地已下载画廊（标签替换、分类/标题/发布时间/大小刷新），未变化时跳过，重复检查开销低。
- 点击文件夹名进入 `#/favorites/<favcat>`：该文件夹的画廊网格（复选框、**下载所选**、**移除收藏**），云端画廊内联显示封面与真实大小。
- **收藏夹管理**（`#/favorites/manage`）：**开始扫描重复画廊**把同一作品的不同版本（DL 版 / 无修正 / 不同语言搬运）分组显示，可批量**取消收藏**或**取消收藏并删除本地副本**；误报可用**忽略所选**隐藏，已忽略项目在独立页面可恢复。

### 「download favorites」与「启用」的区别

- 设置里的 **download favorites**：全局**自动定时检查**的总开关（按轮询间隔自动检查并下载缺失画廊）。
- 收藏夹页每个文件夹的**启用**勾选：该文件夹是否参与自动检查、检查时是否下载（未勾选 = 仅记录，绝不下载）。

要自动下载需三者同时满足：总开关开启 + 文件夹已勾选 + 模式为「增量/强制下载」。手动「立即检查」不受总开关限制，但未勾选的文件夹手动检查也只是仅记录。

## 设置（`#/settings`）

- **库根目录**（只读）：每行一个文件系统路径；新下载不会写入这里。
- **下载**：根目录、并发数、画质（普通/原图）、H@H 网络、`max_pages`。
- **账户**：修改密码（改密码会**撤销所有已登录会话**）、切换「需要登录」。
- **ExHentai**：基础 URL 与 `ipb_member_id` / `ipb_pass_hash` / `igneous` cookie，**测试登录**验证；cookie 不会回显。
- **代理**：HTTP 或 SOCKS5（二选一）。
- **标签同步**：扫描/启动后自动同步、间隔、并发，**立即同步标签**。
- **Thumbnails**：自动生成开关、**立即生成**；下方显示缩略图**实时状态**。
- **Telegram**：bot token、chat ID、允许的 user ID，**发送测试消息**验证。
- **翻译自动更新**：间隔（分钟，0=关闭）与**立即更新**。
