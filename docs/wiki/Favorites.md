# 收藏与更新

> 中文 · [English](Favorites-EN) | 属于 [使用指南](Usage) 系列

本文档介绍 GalleryVault 的 ExHentai 收藏夹同步、监控策略、收藏夹查重、以及云端重传更新（Gallery Updates）机制。

## 收藏夹（`#/favorites`）

- 列出十个 ExHentai 收藏文件夹：启用开关、模式（增量下载 / 仅监控 / 强制下载）与轮询间隔；**保存**一次写入。
- **同步收藏夹名称**从 ExHentai 拉取文件夹名。
- **立即检查**扫描该文件夹；**立即检查所有**一次检查全部。
- 每个文件夹显示云端/本地数量与大小；检查进行时名称旁出现**进度环**。
- 每次检查把完整元数据（标题、标签、分类、发布时间、大小）缓存进数据库，并把最新元数据**自动应用**到本地已下载画廊（标签替换、分类/标题/发布时间/大小刷新），未变化时跳过，重复检查开销低。
- **跳过启发式**：连续多次（5 次）检查发现文件夹计数未变化时，会跳过全量重扫（只做计数检查），避免无谓的网络开销与漏检风险；计数一旦变化自动恢复全量检查。
- 点击文件夹名进入 `#/favorites/<favcat>`：该文件夹的画廊网格（支持**标题关键词搜索**、**多维排序**、复选框、**全选**、**下载所选**、**下载所选原图**、**归档下载所选**、**移动所选**、**移除收藏**、**全部/仅本地/仅云端**状态筛选）。**立即检查**会把云端封面预热到本地缓存；进夹只读磁盘（`<img>` 走 `/api/favorites/cover`），不再等外网下图。列表为**页码分页**，默认每页 24 个。
  - **文件夹内搜索与排序**：顶部提供标题即时过滤搜索框，并可按**初次收藏时间**、**最后收藏时间 (默认)**、**发布时间**、**标题**、**体积**进行多维排序。
  - **高级筛选**：提供可折叠高级筛选面板（对齐画廊库），支持本地星级评分、页面范围、文件大小、发布日期、上传者、画质、语言及本地列表筛选，并显示激活筛选数量提示。
  - **全选**：点进某收藏夹后工具栏「清除选择」左侧提供全选；选中范围为当前已渲染卡片（无限滚动未入 DOM 的不选），滚动后再点一次可并入新卡。
  - **移动所选**：选中画廊后可批量转移到其他收藏夹（0~9 号），并同步更新 ExHentai 云端与本地记录。
- 收藏夹总览页的**下载缺失项目**：为所有已检查文件夹下载缺失的封面缩略图文件（供列表/查重内联显示）。
- 需要先配置 **ExHentai cookie**（见 [入门与配置](Usage#配置-exhentai-cookie) 或 [系统设置](Settings) → ExHentai，存入数据库时加密），否则检查会失败、无法获取收藏夹内容与封面。
- **归档下载与更新**：支持通过 ExHentai 官方整包 zip 通道以归档形式下载或更新选中画廊（弹出费用/余额预览，锁定原图或重采样档位）；详细执行流程、断点续传机制与降级策略请参阅 [下载管理 → 归档下载](Downloads#归档下载exhentai-archive)。

## 收藏夹管理与查重（`#/favorites/manage`）

- **开始扫描重复画廊**把同一作品的不同版本（DL 版 / 无修正 / 不同语言搬运）分组显示，可批量**取消收藏**或**取消收藏并删除本地副本**（会删除该 gid 在库根下的全部物理副本；若某个副本因只读挂载/权限删除失败，会在 toast 与日志页提示，且该画廊 DB 行会保留、不会被下次扫描当作新画廊重新入库）；误报可用**忽略所选**隐藏，已忽略项目可在「已忽略项目」页（`#/favorites/ignored`）查看并恢复所选。

## 更新画廊（`#/updates`）

- 收藏夹页顶行入口直达（直接访问 `#/updates` 仍可用）。ExHentai 把画廊**重传**时会给它一个新 gid，收藏夹会跟随新版本，而本地磁盘留下旧 gid 的副本。本页自动列出这类「本地是旧版」的画廊（判定：本地 gid 不在任何收藏夹、但标题规范化后与某个收藏项相同），每行显示 `旧 gid → 新 gid`。
- 勾选后点**更新选中**：先下载新版本，**下载成功后再删除旧版本地副本**（旧版阅读进度随之重置）。若增量/强制检查**已经把新 gid 下载入库**，检测会直接删旧本（本页条目随之消失），不必再点更新选中；收藏夹入队也会把已有更新行挂到该下载任务上，入库成功同样自动收尾。
- 检测在每次收藏夹检查完成后自动执行，也可用**立即检测**手动触发；误判可**忽略选中**（忽略项即使新本已在库也不会自动删旧），已忽略项目在 `#/updates/ignored` 可恢复。
- 下载任务从任务页删除后，对应更新项会标记为**失败**并保留在此页；在**失败**筛选下可用**删除所选**彻底清除这些记录（不影响任务页，仅清理本页历史记录）。

## 「download favorites」与「启用」的区别

- 设置里的 **download favorites**：全局**自动定时检查**的总开关（按轮询间隔自动检查并下载缺失画廊）。
- 收藏夹页每个文件夹的**启用**勾选：该文件夹是否参与自动检查、检查时是否下载（未勾选 = 仅记录，绝不下载）。新夹默认不启用，需勾选并保存。

要自动下载需三者同时满足：总开关开启 + 文件夹已勾选 + 模式为「增量/强制下载」。手动「立即检查」不受总开关限制，但未勾选的文件夹手动检查也只是仅记录。

开启**「定时扫描大画廊走归档下载」**后，自动检查的候选画廊会先批量取页数：超过**「归档页数阈值」**（0=全部）的走归档下载（档位 = 「归档下载质量」），其余仍逐页。阈值取页数时，元数据拉取失败会安全回退为逐页下载；归档通道拿不到某个画廊（如所选画质档不存在）时也默认自动降级为逐页兜底（设置可关，详见 [下载管理](Downloads)）。

## 三种模式的区别

每次检查都会把文件夹里的**全部**画廊记入本地记录（`favorite_items`），三种模式的差异只在"候选下载哪些"：

- **增量下载**：只下载**首次出现**的画廊 —— 即本地记录里还没有的 gid（新加进收藏夹的）。因此**检查过一次之后，存量收藏设为增量不会下载**（它们早已被记录，不再算"新"）。
- **仅监控**：只记录数量/大小，绝不下载。
- **强制下载**：忽略"本地记录"这一层过滤，把文件夹里**所有不在本地库（galleries 表）的画廊**全部排队下载。已在本地库的画廊仍会被跳过，不会重复下。

增量与强制都会跳过本地库已有的画廊。已检查过的存量收藏要下载时，请临时把模式切到**强制下载**再「立即检查」（或在 `#/favorites/<favcat>` 里勾选「下载所选」），下完切回「增量下载」即可恢复"只跟新收藏"。
