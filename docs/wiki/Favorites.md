# 收藏与更新

> 中文 · [English](Favorites-EN) | 属于 [使用指南](Usage) 系列

ExHentai 收藏夹同步、监控模式、收藏夹查重与重传换 GID 更新管理。

## 收藏夹（`#/favorites`）

- **前置前提**：需预先配置 ExHentai Cookie（详见 [入门与配置](Usage#配置-exhentai-cookie) 或 [系统设置](Settings) → ExHentai，配置在数据库中以密文存储）。未配置 Cookie 时检查会失败，无法读取收藏夹内容与封面。
- **总览与基础控制**：
  - 列出 10 个 ExHentai 收藏文件夹（0~9 号），显示云端数量、本地数量与占用体积；检查运行过程中对应文件夹名称旁显示进度环。云端计数页解析失败时该次结果按「未知」处理（不当作 0），列表回退显示本地已记录的云端数量，未知结果只短暂缓存（约 60 秒）后重试。
  - **同步收藏夹名称**：从 ExHentai 拉取云端自定义文件夹名称。
  - **立即检查**：手动扫描当前指定文件夹；**立即检查所有**：一次性检查全部文件夹。
  - **保存**：修改各文件夹的启用开关、模式与轮询间隔后统一提交保存。
  - **下载缺失项目**：在总览页为所有已检查文件夹补全缺失的本地封面缩略图缓存文件（每批 25 个，供列表展示与查重内联显示）。收藏元数据同步正在运行时重复触发会返回 409，不会并发启动第二轮。
- **元数据缓存与跳过规则**：
  - 每次检查拉取完整元数据（标题、标签、分类、发布时间、大小）缓存至本地数据库；若本地已存在已下载画廊，会自动应用刷新元数据（更新标签、分类、标题、发布时间与大小），元数据未变动时跳过更新。抓取结果缺字段（如部分条目缺少标题、发布时间、体积或标签）时保留已缓存的旧值，不会用空值覆盖，`expunged` 标记一旦为真也保持为真。
  - 检查时自动把云端封面预热至本地磁盘缓存，后续进入文件夹只读本地磁盘（`/api/favorites/cover?gid={gid}&token={token}`），无需等待外网请求。
  - **跳过启发式（仅定时轮询生效）**：定时检查时，若云端计数与本地已知计数一致，立即跳过全量扫描；连续跳过 4 次后，第 5 次强制执行全量扫描。若云端计数发生变化，立即重置计数并执行全量扫描（点击「立即检查」不触发跳过，直接全量检查）。
  - **列表截断保护**：分页拉取失败或列表提前结束时整次检查按失败处理，不删除本地记录；若一次检查返回的条目少于已记录数的 50% 且已记录 ≥20 条，本次清理（prune）会被跳过并在日志告警，避免把分页截断误判成批量取消收藏。下次完整检查成功后会自动清理真正消失的条目。
  - **云端已清空**：收藏夹页面头部计数为 0 且列表页正常解析时，视为云端已确认清空，本次检查会清理该文件夹的本地记录；解析失败或列表被判定截断时不会清理。
- **文件夹画廊网格（`#/favorites/<favcat>`）**：
  - 点击文件夹名进入画廊网格视图，默认每页 24 项，支持无限滚动与底部分页器兜底。
  - **搜索与排序**：顶部提供标题即时搜索框；支持按初次收藏时间、最后收藏时间（默认）、发布时间、标题、体积多维排序。
  - **筛选**：支持全部、仅本地、仅云端状态筛选；提供可展开的高级筛选面板（支持本地评分、页数范围、文件大小、发布日期、上传者、画质、语言与本地列表筛选）。
  - **全选与移动**：工具栏提供全选当前已渲染卡片功能（滚动载入新卡片后可再次点击并入）；支持批量移动至其他收藏文件夹（0~9 号），操作在 ExHentai 云端确认成功后同步更新本地记录。
- **批量下载与原图升级规则**：

| 操作按钮 | 画质规则 | 未入库画廊处理 | 已入库画廊（已在本地）处理 |
| :--- | :--- | :--- | :--- |
| **下载所选** | 跟随全局设置（缺省重采样） | 正常排队入库 | 跳过（不重复排队；全局设为原图亦不触发升级，避免重复入队） |
| **下载所选原图** | 强制逐页原图画质 | 正常排队入库 | 若本地已是 original 则跳过；若本地为 resample/unknown 则按逐页 original 升级入队，下载入库后删除旧副本（包含 CBZ） |
| **归档下载所选** | 由弹窗费用预览选择 original 或 resample 档位 | 正常排队入库 | 若本地已是 original 则跳过；若本地非 original 且弹窗选择 original 档，则触发整包 original 升级入队，入库后删除旧副本；若选择 resample 档则跳过 |

官方整包归档通道的费用预览、断点续传机制与降级策略参阅 [下载管理 → 归档下载 (ExHentai Archive)](Downloads#归档下载exhentai-archive)。

## 收藏夹查重（`#/duplicates/favorites`）

- **功能入口**：位于 **管理 → 收藏夹重复**（旧路径 `#/favorites/manage` 自动重定向至此）。
- **扫描与处理**：
  - 点击**开始扫描重复画廊**，系统将同一作品的不同版本（如数字版、无修正版、不同语言版本）按作品分组展示。
  - 支持批量**取消收藏**，或**取消收藏并删除本地副本**（删除该画廊 GID 在库根目录下的全部物理文件与 CBZ 副本）。
- **安全与只读保护**：
  - 收藏移除操作以云端确认成功为前提更新本地记录。
  - 云端返回登出、限流或封禁页面时按失败处理：本地收藏状态与文件保持不变，失败的 GID 不会更新本地记录（接口在 `cloud_failed` 中列出）。
  - 若底层存储处于只读挂载状态导致物理文件删除失败，界面弹出提示并记录日志，数据库记录予以保留，防止下次扫描将画廊误判为新项目。
- **误报管理**：对无需处理的项目可点击**忽略所选**；已忽略记录可在 `#/favorites/ignored` 中查看与恢复。

## 更新画廊（`#/updates`）

- **入口与检测机制**：
  - 收藏夹页顶行提供入口直达，亦可直接访问 `#/updates`。
  - 当 ExHentai 画廊被重传时，云端会生成新 GID，收藏夹会跟随新版本，而本地磁盘仍保留旧 GID 副本。本页面自动列出本地包含旧版本的画廊（判定规则：本地画廊 GID 未被任何当前收藏夹包含，但标题规范化后与现有某个收藏项匹配），列表每行显示 `旧 GID → 新 GID`。
  - 检测在每次收藏夹检查完成后自动执行，亦可点击**立即检测**手动触发。
- **更新流程与旧副本清理**：
  - 支持勾选后执行**更新选中**（画质跟随全局设置）、**更新选中原图**（强制逐页原图画质）或**以归档形式更新选中**（弹窗选择档位）。
  - 执行更新时系统先下载新版本；**新版本下载并入库成功后，才会删除旧版本的本地文件副本**（旧版本的阅读进度随之重置）。
  - 若增量检查或强制检查已提前将新 GID 画廊下载入库，检测机制会自动识别并删除旧版本地副本（当前更新页面的对应条目自动清除）。在收藏夹页面批量入队下载时，若存在对应更新记录，也会关联至该下载任务并在入库后自动清理旧版本。
- **失败与忽略处理**：
  - 若在任务管理页删除了正在运行的更新下载任务，对应更新项会标记为**失败**并保留在当前页面；可在**失败**状态筛选下点击**删除所选**清理失败记录（仅清理更新记录列表，不影响下载任务历史）。在最后一页批量删除后若当前页超出新的总页数，列表会自动回到上一页。
  - 对误判项目可点击**忽略选中**（已忽略的项目即使新版本入库也不会自动删除旧版本地副本）；已忽略项目可在 `#/updates/ignored` 中恢复。默认（进行中）视图的 `total` 不含已忽略条目。

## 「download favorites」与「启用」的区别

- **download favorites（全局设置）**：系统设置中自动定时检查的总开关，控制后台是否按轮询间隔自动执行检查与下载。
- **启用（文件夹选项）**：收藏夹配置中针对各个文件夹的独立开关，控制该文件夹是否参与自动定时检查，以及检查时是否允许下载（未勾选时仅作记录，不执行下载）。新建或未启用的文件夹默认不开启，需手动勾选并保存。
- **自动下载触发条件**：
  必须同时满足以下三项条件，系统才会自动下载缺失画廊：
  1. 系统设置中 **download favorites** 全局总开关处于开启状态；
  2. 目标收藏文件夹的**启用**勾选处于开启状态；
  3. 目标收藏文件夹的运行模式设置为**增量下载**或**强制下载**。
- **手动检查行为**：
  手动点击「立即检查」不受全局 **download favorites** 总开关限制；但若目标文件夹未勾选「启用」，手动检查仍然仅记录元数据，不会触发下载。
- **大画廊归档下载联动**：
  开启「定时扫描大画廊走归档下载」后：
  - 自动检查筛选出的候选画廊会预先批量获取总页数。
  - 页数超过「归档页数阈值」（设置为 0 表示全部画廊）的项目自动转为 ExHentai 官方归档整包下载（画质档位按「归档下载质量」执行），其余未超阈值的画廊继续按逐页方式下载。
  - 获取页数失败时，安全回退为逐页下载模式；若官方归档通道无法获取指定档位归档包，系统默认自动降级为逐页下载（可在设置中关闭回退机制，详情参阅 [下载管理](Downloads)）。

## 三种模式的区别

每次检查都会把文件夹里的全部画廊记录到本地数据库（`favorite_items` 表），三种模式的差异在于下载候选范围与已有本地项目的处理：

| 模式 | 是否记录元数据 | 候选下载范围 | 已有本地项目处理 |
| :--- | :--- | :--- | :--- |
| **增量下载** | 是（全量记录） | 仅限**首次出现**的画廊（本地记录中此前不存在的新 GID） | 本地库已存在的画廊直接跳过 |
| **仅监控** | 是（全量记录） | 不下载任何画廊（下载候选为空） | 不执行下载操作 |
| **强制下载** | 是（全量记录） | 文件夹内所有**不在本地画廊库（`galleries` 表）**的画廊 | 本地库已存在的画廊直接跳过，不会重复下载 |

**存量收藏在增量模式下的行为与处理**：
- 在增量下载模式下，一旦某个文件夹完成过一次检查，所有存量画廊均已被写入本地记录，后续即使未曾下载，也不会被视为“首次出现”，因此**不会被增量下载触发**。
- 若需要下载已被记录的历史存量画廊，可临时将文件夹模式切换为**强制下载**后点击「立即检查」（或在单个文件夹页面 `#/favorites/<favcat>` 中勾选目标画廊并点击「下载所选」/「下载所选原图」/「归档下载所选」）；全部排队下载完成后，再切回**增量下载**模式即可恢复仅跟踪新入藏画廊。
