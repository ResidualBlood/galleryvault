# 使用指南

SPA 使用 hash 路由（`#/library`、`#/gallery/7`、…），浏览器刷新与前进/后退无需服务器往返。顶栏可叠加黄条（全局暂停）、红条（Cookie 失效）与图片配额告警。

## 浏览（`#/browse`）

- 默认落地页（空 hash / 未指定路由也到此）：按最新发布倒序展示画廊网格，页码分页。
- **继续阅读卡片区**：顶部自动聚合最近阅读的画廊，展示封面缩略图、进度条与百分比；支持一键直达阅读进度或点击 ✕ 标为未读/重置单本进度。
- 顶部有**标签命名空间入口条**（标签 / 作者 / 角色 / 原作 / 社团 / 女性 / 男性 / 语言）与**随机画廊**按钮（🎲，跳转到随机画廊详情页）。
- 顶栏的**全局搜索框**回车即跳转画廊库并执行标题搜索；全站按 **`/` 键**可直接聚焦搜索框。
- 画廊网格支持**键盘方向键导航**（`←`/`→`/`↑`/`↓` 移动焦点，`Enter` 打开详情页）。

## 历史（`#/history`）

- 按画廊列出阅读历史（最后阅读进度与时间），每项支持一键「开始阅读」直达进度或「✕」单独清除阅读进度。
- **清空历史**：清空时间线足迹（不影响画廊自身的阅读进度条）。
- **清除阅读进度**：弹窗确认后重置所有画廊的阅读进度（全部标为未读/进度归零）。
- 阅读位置由阅读器自动保存（画廊详情/阅读器进入时自动定位）。

## 首次运行向导（`#/welcome`）

首次部署后（仍在使用默认密码时），登录会自动进入 `#/welcome` 三步向导：

1. **修改默认密码**：把内置默认密码 `p1a2s3s4` 改成你自己的强密码（不可跳过，可随时补）。
2. **连接 ExHentai**：选择 base URL（ExHentai 里站 / E-Hentai 外站 / 自定义代理子域）并填入 `ipb_member_id` / `ipb_pass_hash` / `igneous` cookie，可用「测试登录」验证。（可跳过）
3. **填充画廊库**：点击「扫描库」或「立即检查所有收藏夹」。（可跳过）

每步完成会显示 ✓；点「完成设置」进入主界面。已配置的实例登录不会强制进入，可在地址栏手动访问 `#/welcome`。

## 画廊库（`#/library`）

- 按标题搜索、按分类过滤、多维排序与阅读状态过滤，分页浏览索引的画廊。
- **多维排序**：支持按**入库时间 (默认)**、**发布时间**、**标题**、**页数**、**体积**、**评分**升降序排列，底层建立对应数据库索引，万本库秒级响应。
- **阅读状态筛选**：支持快速筛选**全部**、**未读**（从未阅读或进度为0）、**在读**（已读部分页码）、**已读完**（读至末页）画廊。
- **页数与评分区间**：工具栏可填最少/最多页数、最低评分（≥2 / ≥3 / ≥4 / ≥4.5）；与排序、阅读状态、标签筛选一并粘性保存（点标签、返回详情不会丢）。
- **「不在收藏夹」筛选**：分类下拉末尾新增「不在收藏夹」项，只显示本地有、但不在任何 ExHentai 收藏夹里的画廊（无 gid 的本地归档天然属于此类；已被已收藏新版替代的旧画廊会自动排除并归入「更新画廊」）；收藏夹从未同步过时该项等价于「全部」。
- 此页为**无限滚动**：滚动接近底部时自动加载下一页（默认每页 24 个，可在页尾选择页大小）；底部页码分页器保留作兜底。**每页选择会被记住**（浏览器本地保存），阅读往返后仍沿用。
- 点击封面进入画廊详情页。
- **多标签筛选（AND / OR）与排除标签（`-tag`）**：
  - 点击标签提示、画廊详情页或标签云中的标签会追加进当前筛选；画廊卡片上的标签支持**普通点击 = 加入筛选**（`ns:name`），**Shift / Alt / Ctrl / Cmd + 点击 = 加入排除筛选**（`-ns:name`，如 `Shift+点击 female:lolicon → -female:lolicon`），卡片内点击已做 `stopPropagation` 不会误触进入详情页；
  - 标签胶囊栏支持点击 **AND / OR** 模式切换；
  - 支持排除标签（输入 `-namespace:name` 或 `-tag`，如 `-female:lolicon`），以红色警示样式显示，匹配画廊将自动排除；排除筛选同样受「删除当前筛选」与粘性上下文保护。
- **标签筛选靠「点击」而非自动猜测**：搜索框输入时会弹出标签建议，**点击建议**才把该标签加入筛选（该词会从输入文字中消费掉，不重复作为标题关键词）；或使用显式 `ns:name` 语法（如 `parody:touhou`）、标签云 / 画廊详情页里的标签。直接回车（不含 `ns:name`）**只做标题文字搜索**，不会被自动识别成标签筛选。
- **多词搜索 = 每词都必须出现**：标题搜索把空格分隔的多个词**逐词 AND**（各自作为独立子串、位置/顺序无关），如 `mimu gif` 命中标题同时含 mimu 与 gif 的画廊；单词与中文整句搜索行为不变。
- **批量加收藏**：勾选后点「批量加收藏」，选 0–9 号夹，分批 25 本提交；**仅云端成功的 gid 写入本地**，无 gid 的本地归档会跳过并 toast。
- **批量与筛选删除**：
  - 勾选画廊卡片后顶部显示「批量删除」，可选择是否同步删除磁盘物理文件（**不删盘则进入 `#/recycle`「用户删除」**，可恢复）；
  - 支持「删除当前筛选」一键删除当前分类、搜索、阅读状态或标签匹配的全部画廊；后端具有 5000 本安全上限熔断保护（超过返回 409，需缩小筛选范围），分批 500 本安全处理，磁盘只读时会保留 DB 记录并在日志报告。
- **扫描库**触发文件系统扫描：新归档入库，目录里找不到的画廊进入 `#/recycle`「扫描失踪」（可恢复；彻底删除才从索引移除）。扫描完成会发 Telegram 通知；若发现重复副本，消息会附上「N duplicate-copy group(s) found (gid …)」提醒去「重复副本」页处理。扫描在**全局暂停**时不会启动（返回 `paused`）。

## 重复副本（`#/duplicates`）

- 同一画廊（同一 gid）出现在**多个扫描目录**时（如 EhViewer 下载目录 + CBZ 归档 + 手动复制），扫描会按**重复副本策略**（设置页 `duplicate_policy`）自动保留一份，并把其余副本记录在「重复副本」页。
- 策略选项：`keep_first`（默认，已入库的副本优先）、`prefer_more_pages`（页数多者）、`prefer_newer`（发布日期新者）、`prefer_larger` / `prefer_smaller`（体积大/小者）、`manual`（从不自动处理，全部列出待人工决定）。
- 每组重复展示每个副本的封面缩略图、标签、页数、大小与发布时间；带「当前保留」徽标的是当前索引指向的副本。
- 操作：**保留此副本**（把索引改指向该副本）、**保留并删除其他副本**（删除磁盘上其余副本文件，仅限扫描目录内的路径）、**忽略该组**（隐藏，可恢复）。
- 页面上的**扫描库**按钮可立即重新扫描刷新列表；被忽略的组在副本情况变化前不会再次弹出。

## 回收站（`#/recycle`）

- 两个分页：**用户删除**（库页删除且不删盘）与 **扫描失踪**（扫描时目录里找不到）。
- 勾选后 **恢复** 重新出现在库中；**彻底删除** 会再确认是否删磁盘文件（删盘后扫描不会重新入库）。

## 缺页体检（`#/integrity`）

- 列出已记录页数与已落盘页数不一致的画廊（未填页数、故意 `max_pages` 截断的不算）。
- 勾选后「修复 / 重下」只补缺失页。

## 画廊详情（`#/gallery/<id>`）

- 展示元数据（大小、自适应单位）、标签与页面缩略图。
- 页面缩略图按页码分页，**每页默认 30 张**（可切换 5/30/50/100/200/500），**选择会被记住**，读完返回后保持。
- **缩略图分页自动定位到阅读位置**：无显式 `?page=` 参数时，缩略图停在阅读进度所在的页码分页（从阅读器返回即回到刚看的那页附近）；手动翻过缩略图页（URL 带 `?page=`）则以它为准。
- **点击标签**可跳转到画廊库，把该标签**追加**进当前筛选（继续叠加可多标签组合）。
- **开始阅读**打开阅读器（定位到上次阅读位置）。
- **打开原站**：新标签页跳转到 ExHentai 上对应的画廊页，链接按设置里的 base URL 生成（`{base}/g/{gid}/{token}/`），需浏览器已登录 EH；本地无 token 的画廊不显示此按钮。
- **同步标签**：从 ExHentai 拉取该画廊标签/元数据；收藏夹已缓存时直接复用缓存（免网络）。
- 使用**外站（e-hentai.org）**时，里站专属画廊会**暂停**标签同步（不会被误判为已删除、分类不受影响），在设置里切回 `exhentai.org` 后自动恢复。
- 画廊属于哪些收藏夹会以徽标显示；未收藏画廊支持**加入收藏**（选择 0~9 号收藏夹弹窗），已收藏画廊支持**更改收藏夹**（Move）与**取消收藏**，且严格以 ExHentai 云端成功为前提同步本地。
- **原图 / 重采样**：收藏夹徽标旁显示本地副本的画质（原图 / 重采样），画质未知时不显示。画质在下载时记录，存量画廊通过「本地文件大小 vs ExHentai 原图大小」推断——收藏夹同步（轮询 / 立即检查 / 拉取缺少项目）与**扫描库**完成时自动补齐。
- **升级为原图**：非原图且有 ExHentai gid 的画廊，工具栏显示两个按钮——
  - **下载原图**：逐张下载原图（不耗 GP，进度见下载页）；画廊在 ExHentai 上无原图时不会入队。
  - **归档形式下载原图**：弹出费用/余额预览（锁定原图档，原图不可用或 GP 不足时禁用），走 ExHentai 归档（zip）通道。
  - 原图下载完成后，旧的重采样副本自动删除（页数一致才删；目录只读删除失败时会提示手动删除，任务不受影响）。

## 阅读器（`#/reader/<id>/<page>`）

- 逐页流式加载。用 **←/→ 方向键**、**空格**或**点击图片**翻页。
- **精准跳页**：顶部工具栏显示页码输入框（支持直接输入数字回车跳转），全屏或阅读中按 **`G` 键**即可聚焦跳页输入框或唤起跳页弹窗。
- **多阅读模式切换（LTR / RTL 日漫 / 双页并排）**：工具栏「模式」按钮可在**顺序 (LTR)**、**日漫 (RTL)**、**双页并排**与**双页日漫**间切换，偏好自动持久化。RTL 模式下翻页按键与点击方向智能反转；双页模式在宽屏下自动将成对页面并排展示（封面单页居中）。
- **移动端手势**：支持移动端双击局部缩放（2.2x）及双指捏合缩放（Pinch-to-zoom）。
- **翻过最后一页自动跳转下一画廊**。
- 预加载后三页（双页模式预加载后四页），翻页即时。
- **页面原图浏览器缓存 1 小时**：返回上一页或重复阅读同一画廊直接复用浏览器缓存，不重复下载；缩略图缓存 24 小时。
- 进度条显示 `页 / 总页 · 大小`（自适应 B/KB/MB/GB）。
- 阅读位置自动保存。
- **全屏按钮（或按 `F`）进入图片全屏**：仅图片铺满屏幕（等比 `object-fit: contain`，黑色背景），阅读器工具栏与翻页按钮隐藏；全屏期间翻页（方向键 / 空格 / 点击图片）就地换图、**保持全屏不退出**；翻过末页/回首页自动退出全屏再跳转。`Esc` 退出并恢复原先的「适应」模式、把 URL 同步到当前页。
- **适应模式切换**：阅读器工具栏的「适应」按钮在几种显示模式间切换（默认按页面宽度缩放），对不同长宽比页面更友好；退出全屏后恢复进入全屏前的模式。
- 从画廊库搜索进入的画廊，**阅读器内全程保留搜索上下文**：翻页（方向键 / 空格 / 点击图片 / 点缩略图 / 自动跳下一本）后，左上角「← 详情」与详情页的「← 画廊库」仍带当前搜索关键词与标签筛选，不会回到未筛选的画廊库。

## 标签（`#/tags`）

- 搜索本地标签体系并查看使用次数；用顶部分组筛选（全部 / 标签 / 作者 / 角色 / 原作 / 社团 / 女性 / 男性 / 语言 / 分类）。
- **翻页时顶部的分组筛选条保持不变**。
- 搜索框支持中文补全（与顶栏相同的翻译反向匹配，如输入「巨乳」）；**点选建议留在标签页并过滤标签云**（切到对应命名空间，用英文名检索）。直接提交中文也会按翻译匹配本地已有标签。右侧按钮为「搜索标签」。顶栏搜索仍搜画廊，点选进资料库。
- **点击标签云中的标签**会跳转到画廊库，把该标签**追加**进筛选（多标签 AND 组合）；画廊详情页里的标签同样可追加。
- 中文界面下标签显示翻译；多值标签（`A | B`）只显示翻译的部分（未翻译的英文别名自动隐藏）。
- 结果固定每页 100 条（无页大小选择器；后端 API 上限 500）。

## 下载页（`#/downloads`）

- **粘贴链接 / GID 批量入队**：顶部「添加下载」面板支持多行 URL 或 `gid/token`。**加入逐页**可覆盖默认画质；**归档下载**弹出与收藏夹相同的 GP/清晰度预览后再入队。任务标题按设置的「标题显示」（英文/日文）解析，不再只显示 `gid xxx`。
- **有更新则下新版**：入队或开下时若 ExHentai 标明该画廊已被替换，自动改下新 gid（最多 5 跳）；404/已删除不重试，列表与 Telegram 用人话提示。详情页「给这本下原图」不跟新版。
- **全局暂停**：页内暂停按钮与 Telegram `/pause` 为同一开关（见设置）；停 claim 和新页、扫描也暂停，重启仍在；顶栏黄条可与 Cookie 红条叠加。
- **GP 与图片配额**：页顶显示缓存的 GP 余额与 Image Limit（约 30 分钟刷新）；配额超过约 80% 时顶栏告警，建议暂停以免 509。
- 列出下载任务及其状态（等待 / 下载中 / 成功 / 失败 / 已取消），可按状态筛选。
- 每行标题旁有**下载方式徽标**：归档任务显示「归档 · 原图/重采样」，逐页 H@H 图片下载显示「逐页」，一眼区分两种通道。
- 活动任务显示**实时进度条**（`当前/总` + 百分比），列表每 2 秒自动刷新。
- **重试可续传**：仅补下缺失/失败的页，已落盘页面跳过。
- **失败自动自愈**：瞬时错误（图片超时、ExHentai 挑战、H@H 慢节点）会自动重新入队，按**指数退避**（30 秒→2 分→8 分→30 分→1 小时→…→最长 6 小时）重试，最多 10 次后才标记「失败」；周期巡检还会把仍有剩余重试次数的历史失败任务自动重新激活，手动「重试」基本用不上。
- 等待/下载中可**取消**；失败/取消/成功可**重试**（单个或勾选批量）。
- **清除全部成功**：一键删除所有 `success` 任务记录（确认框会显示条数）；只清任务列表，**不删除已入库画廊文件**。失败/取消/进行中任务不受影响。
- **下载完成立即入库**：画廊行/页面/标签直接从下载结果写入索引（含封面缩略图，按需生成），**无需全量扫描**；存储签名与扫描器一致，后续手动「扫描库」会跳过不再重复入库。
- 配置 Telegram 后，下载成功/失败、扫描完成、**改下新版**、**404/删除**会收到通知；下载通知默认**汇总**（改道为单独一条；404 算失败），设置里可切"即时 / 仅失败 / 关闭"。

## 日志页（`#/logs`）

分为两个标签页：

1. **后台任务活动（Task Activity）**：展示后台任务（库扫描、标签同步、缩略图生成、收藏元数据同步）：
   - **进行中**：每行 = 开始时间 · 任务名 · `进行中 · done/total` · 进度条 · 描述 · **取消**按钮；多任务可并排多行。
   - **已完成**：开始时间 · 任务名 · 状态徽标（成功/失败/已取消）· 描述与原因 · **耗时** · 完成时间；已完成任务不再显示进度条。
2. **系统运行时日志（System Logs）**：查看后端服务运行时的实时诊断日志（内存环形缓冲区）：
   - **动态调级**：可在线切换全局日志级别（`DEBUG` / `INFO` / `WARNING` / `ERROR`），无需重启容器；
   - **实时筛选与搜索**：支持按最低日志级别（`INFO+` / `WARN+` / `ERROR+`）筛选与文本关键字快速检索；
    - **异常堆栈与上下文**：错误自动展示可展开的 Traceback 堆栈，并带请求 ID、Worker 协程上下文（`gid` / `task_id`）与敏感凭据自动脱敏（`ipb_*` Cookie、Telegram Token、密钥等安全遮蔽）；
    - **导出日志**：工具栏「导出日志」下载 `galleryvault.log`（环形缓冲 + 落盘轮转文件，`GET /api/system/logs/download`），便于把诊断归档发出；
    - **噪音过滤**：httpx 成功请求（2xx/3xx，含 Telegram `getUpdates` 30s 长轮询）不进入本页；4xx/5xx 与业务 WARNING/ERROR（如 bot 轮询失败、通知发送失败）仍保留。

页面每 2~3 秒自动轮询刷新。设置里的「立即同步标签 / 立即生成 / 立即更新翻译」触发后也会在此留痕。

> 提示：如需跨容器查看 Nginx、后端及数据库的原始实时输出流，可参考 [部署](Deployment) 文档按需集成 Dozzle 日志面板。

## 收藏夹（`#/favorites`）

- 列出十个 ExHentai 收藏文件夹：启用开关、模式（增量下载 / 仅监控 / 强制下载）与轮询间隔；**保存**一次写入。
- **同步收藏夹名称**从 ExHentai 拉取文件夹名。
- **立即检查**扫描该文件夹；**立即检查所有**一次检查全部。
- 每个文件夹显示云端/本地数量与大小；检查进行时名称旁出现**进度环**。
- 每次检查把完整元数据（标题、标签、分类、发布时间、大小）缓存进数据库，并把最新元数据**自动应用**到本地已下载画廊（标签替换、分类/标题/发布时间/大小刷新），未变化时跳过，重复检查开销低。
- **跳过启发式**：连续多次（5 次）检查发现文件夹计数未变化时，会跳过全量重扫（只做计数检查），避免无谓的网络开销与漏检风险；计数一旦变化自动恢复全量检查。
- 点击文件夹名进入 `#/favorites/<favcat>`：该文件夹的画廊网格（支持**标题关键词搜索**、**多维排序**、复选框、**下载所选**、**下载所选原图**、**归档下载所选**、**移动所选**、**移除收藏**、**全部/仅本地/仅云端**状态筛选），云端画廊内联显示封面与真实大小。列表为**页码分页**，默认每页 24 个。
  - **文件夹内搜索与排序**：顶部提供标题即时过滤搜索框，并可按**初次收藏时间**、**最后收藏时间 (默认)**、**发布时间**、**标题**、**体积**进行多维排序。
  - **移动所选**：选中画廊后可批量转移到其他收藏夹（0~9 号），并同步更新 ExHentai 云端与本地记录。
- 收藏夹总览页的**下载缺失项目**：为所有已检查文件夹下载缺失的封面缩略图文件（供列表/查重内联显示）。
- 需要先配置 **ExHentai cookie**（设置 → ExHentai，存入数据库时加密），否则检查会失败、无法获取收藏夹内容与封面。
- **收藏夹管理**（`#/favorites/manage`）：**开始扫描重复画廊**把同一作品的不同版本（DL 版 / 无修正 / 不同语言搬运）分组显示，可批量**取消收藏**或**取消收藏并删除本地副本**（会删除该 gid 在库根下的全部物理副本；若某个副本因只读挂载/权限删除失败，会在 toast 与日志页提示，且该画廊 DB 行会保留、不会被下次扫描当作新画廊重新入库）；误报可用**忽略所选**隐藏，已忽略项目在独立页面可恢复。
- **更新画廊**（`#/updates`，收藏夹页顶行入口）：ExHentai 把画廊**重传**时会给它一个新 gid，收藏夹会跟随新版本，而本地磁盘留下旧 gid 的副本。本页自动列出这类「本地是旧版」的画廊（判定：本地 gid 不在任何收藏夹、但标题规范化后与某个收藏项相同），每行显示 `旧 gid → 新 gid`。勾选后点**更新选中**：先下载新版本，**下载成功后再删除旧版本地副本**（旧版阅读进度随之重置）。若增量/强制检查**已经把新 gid 下载入库**，检测会直接删旧本（本页条目随之消失），不必再点更新选中；收藏夹入队也会把已有更新行挂到该下载任务上，入库成功同样自动收尾。检测在每次收藏夹检查完成后自动执行，也可用**立即检测**手动触发；误判可**忽略选中**（忽略项即使新本已在库也不会自动删旧），已忽略项目在 `#/updates/ignored` 可恢复。下载任务从任务页删除后，对应更新项会标记为**失败**并保留在此页；在**失败**筛选下可用**删除所选**彻底清除这些记录（不影响任务页，仅清理本页历史记录）。
- **归档下载（ExHentai archive，整包 zip）**：官方归档通道——ExHentai 服务器把整个画廊打包成 zip（消耗 **GP**），客户端用**单连接**流式下载，大画廊远比逐页 H@H 快。入口三处共用一个执行器：
  - 收藏夹 `#/favorites/<favcat>` 与更新画廊 `#/updates` 工具栏的**「归档下载所选」/「以归档形式更新选中」**：点击后先弹**费用预览**（只读、不扣 GP）——顶部显示当前可用 GP，列表每项列出原图/重采样的费用与大小，缺档标红；选择档位后确认才入队。原图 = 完整分辨率原图，重采样 = 服务器固定一级重采样（默认档，GP 与流量都省）。
  - **「下载所选原图」/「更新选中原图」**：仍逐页下载，但**强制原图画质**（无视全局画质设置）。
  - **定时扫描**：设置里开启「定时扫描大画廊走归档下载」并设**页数阈值**后，收藏夹自动检查时页数超过阈值的画廊走归档（档位用「归档下载质量」），其余照旧逐页。阈值 0 = 全部归档。
  - 归档任务占 `download_concurrency` 槽位，与逐页任务同队先进先出；同一 gid 已有逐页/归档任务在队列时，再点归档会提示跳过。
  - **可靠性**：zip 断点续传（Range），`quality + zip 下载链接` 持久化在 `.gv-{gid}/.archive.json`，**重试只续传、不重复打包、不重复扣 GP**；zip 损坏会删除后重新打包；归档通道无法服务该画廊时（所选画质档不存在、GP 不足、归档损坏）默认**自动降级为逐页下载**（不扣 GP、走 H@H），设置里可关闭「归档不可用降级为逐页下载」，关闭后直接标记失败、不烧自动重试次数。下载完成走与逐页相同的收尾链：写入 `.ehviewer`/`.galleryvault.json` 元数据、发通知、立即入库、更新画廊时删除旧版。

### 「download favorites」与「启用」的区别

- 设置里的 **download favorites**：全局**自动定时检查**的总开关（按轮询间隔自动检查并下载缺失画廊）。
- 收藏夹页每个文件夹的**启用**勾选：该文件夹是否参与自动检查、检查时是否下载（未勾选 = 仅记录，绝不下载）。

要自动下载需三者同时满足：总开关开启 + 文件夹已勾选 + 模式为「增量/强制下载」。手动「立即检查」不受总开关限制，但未勾选的文件夹手动检查也只是仅记录。

开启**「定时扫描大画廊走归档下载」**后，自动检查的候选画廊会先批量取页数：超过**「归档页数阈值」**（0=全部）的走归档下载（档位 = 「归档下载质量」），其余仍逐页。阈值取页数时，元数据拉取失败会安全回退为逐页下载；归档通道拿不到某个画廊（如所选画质档不存在）时也默认自动降级为逐页兜底（设置可关）。

### 三种模式的区别

每次检查都会把文件夹里的**全部**画廊记入本地记录（`favorite_items`），三种模式的差异只在"候选下载哪些"：

- **增量下载**：只下载**首次出现**的画廊 —— 即本地记录里还没有的 gid（新加进收藏夹的）。因此**检查过一次之后，存量收藏设为增量不会下载**（它们早已被记录，不再算"新"）。
- **仅监控**：只记录数量/大小，绝不下载。
- **强制下载**：忽略"本地记录"这一层过滤，把文件夹里**所有不在本地库（galleries 表）的画廊**全部排队下载。已在本地库的画廊仍会被跳过，不会重复下。

增量与强制都会跳过本地库已有的画廊。已检查过的存量收藏要下载时，请临时把模式切到**强制下载**再「立即检查」（或在 `#/favorites/<favcat>` 里勾选「下载所选」），下完切回「增量下载」即可恢复"只跟新收藏"。

## 设置（`#/settings`）

- **库根目录**：每行一个文件系统路径；新下载不会写入这里。删除画廊时若挂载可写会一并删除这里的对应文件，若为只读挂载则删除失败并在 toast 与日志页提示。
- **下载**：根目录、并发画廊数、**单画廊并发页数**（默认 4——H@H 节点对同一出口 IP 的并发连接数有限，设太高会顶穿限制、在线路不稳时大量报连接错误；求稳就保持低值，线路干净想榨带宽再调高）、画质（普通/原图）、**归档下载质量**（归档默认档位）、**归档不可用降级为逐页下载**（默认开；归档通道无法服务该画廊时自动转逐页，不扣 GP、走 H@H）、H@H 网络、`max_pages`。慢速 H@H 节点看门狗：**单图最大耗时（秒）**、**慢速预热窗口（秒）**、**单图最低速度（KB/s）**——超过总时长预算、或预热窗口后平均速度低于下限的单张图片会被中断并按退避重试，不再长时间拖住整个画廊。
- **标题显示**（下载设置组内）：`japanese`（默认，日文标题优先）/ `english`（英文标题优先）/ `directory`（目录名）。画廊库、浏览、画廊详情、收藏夹（含纯云端项）、收藏夹查重与重复副本去重页的标题都跟随此设置。
- **下载标题**（下载设置组内）：控制下载目录的文件命名——`japanese`（默认，`gid-日文标题`）/ `english`（`gid-英文标题`）。与显示用「标题显示」相互独立；已下载的画廊会复用原有目录，切换设置不会改名或重复下载。
- **账户**：修改密码（改密码会**撤销所有已登录会话**）、切换「需要登录」。
- **ExHentai**：基础 URL 与 `ipb_member_id` / `ipb_pass_hash` / `igneous` cookie，**测试登录**验证；cookie 不会回显。启动时探活、之后每 30 分钟；失效或无里站权限时顶栏红条并链到设置（登录后也会立刻刷新一次）。
- **代理**：HTTP 或 SOCKS5（二选一）。
- **标签同步**：扫描/启动后自动同步、间隔、并发，**立即同步标签**。
- **Thumbnails**：自动生成开关、**立即生成**；下方显示缩略图**实时状态**。
- **Telegram**：bot token、chat ID、允许的 user ID，**发送测试消息**验证；**通知级别**（汇总 / 即时 / 仅失败 / 关闭）与**通知语言**（中文 / English）——下载、扫库、收藏夹检查与 bot 回复统一用该语言发送，消息采用 Telegram HTML 格式（标题加粗、gid 等宽），画廊标题保持原文不翻译。
- **Telegram bot 控制命令**（在「允许的 user ID」账号发给 bot）：`/pause` 暂停接收新 URL（暂停期间粘贴的画廊 URL 会被忽略、不入队）、`/resume` 恢复接收、`/status` 查看暂停状态；`/pause` 为**全局暂停**（持久化到 `app_config.user_settings`，重启后仍生效）：**停止 claim 新画廊 + 停止派发新页（当前页下完即停，已入队的画廊不丢，恢复后继续）**，同时暂停**自动扫描**与 **Web 端新扫描**（扫描触发返回 `paused`），Web 下载页的暂停按钮与 Bot 的 `/pause` / `/resume` 操作**同一开关**（`GET/POST /api/pause`），顶栏黄条与 Cookie 红条可叠加显示。**直接粘贴画廊 URL**（如 `https://exhentai.org/g/2325283/d3722b6aa8/`）会解析 gid/token 并立即入队下载，bot 回复带**标题**（有新版会说明旧→新 gid；404/删除则提示未入队）。
- **翻译自动更新**：间隔（分钟，0=关闭）与**立即更新**。
