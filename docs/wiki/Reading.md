# 画廊详情与阅读

> 中文 · [English](Reading-EN) | 属于 [使用指南](Usage) 系列

本文档介绍 GalleryVault 的画廊详情信息展示、元数据同步操作以及网页端阅读器特性。

## 画廊详情（`#/gallery/<id>`）

- 展示元数据（大小、自适应单位）、标签与页面缩略图。
- 页面缩略图按页码分页，**每页默认 30 张**（可切换 5/30/50/100/200/500），**选择会被记住**，读完返回后保持。
- **缩略图分页自动定位到阅读位置**：无显式 `?page=` 参数时，缩略图停在阅读进度所在的页码分页（从阅读器返回即回到刚看的那页附近）；手动翻过缩略图页（URL 带 `?page=`）则以它为准。
- **点击标签**可跳转到画廊库，把该标签**追加**进当前筛选（继续叠加可多标签组合）。
- **开始阅读**打开阅读器（定位到上次阅读位置）。
- **导出 CBZ**：把当前画廊打成 CBZ 下载。库里已是 `.cbz` 的直接给出原文件；目录画廊按页序打包（不改落盘格式）。
- **打开原站**：新标签页跳转到 ExHentai 上对应的画廊页，链接按设置里的 base URL 生成（`{base}/g/{gid}/{token}/`），需浏览器已登录 EH；本地无 token 的画廊不显示此按钮。
- **同步标签**：从 ExHentai 拉取该画廊标签/元数据；收藏夹已缓存时直接复用缓存（免网络）。
- 使用**外站（e-hentai.org）**时，里站专属画廊会**暂停**标签同步（不会被误判为已删除、分类不受影响），在设置里切回 `exhentai.org` 后自动恢复。
- **本地星级 / 笔记 / 自定义标签**：详情页可打 1–5 星、写笔记、加 `local:` 标签（不覆盖 EH 标签；标签同步会保留 `local:`）。库可按本地星级筛选。
- 画廊属于哪些收藏夹会以徽标显示；未收藏画廊支持**加入收藏**（选择 0~9 号收藏夹弹窗，云端成功后写入本地并迁出其它夹），已收藏画廊支持**更改收藏夹**（Move）与**取消收藏**，且严格以 ExHentai 云端成功为前提同步本地。**收藏备注**可编辑（走 EH applyfav / `favnote`，云端成功才写本地）；收藏夹列表会显示备注。
- **原图 / 重采样**：收藏夹徽标旁显示本地副本的画质（原图 / 重采样），画质未知时不显示。画质在下载时记录，存量画廊通过「本地文件大小 vs ExHentai 原图大小」推断——收藏夹同步（轮询 / 立即检查 / 拉取缺少项目）与**扫描库**完成时自动补齐。
- **升级为原图**：非原图且有 ExHentai gid 的画廊，工具栏显示两个按钮——
  - **下载原图**：逐张下载原图（不耗 GP，进度见下载页）；画廊在 ExHentai 上无原图时不会入队。
  - **归档形式下载原图**：弹出费用/余额预览（锁定原图档，原图不可用或 GP 不足时禁用），走 ExHentai 归档（zip）通道（详见 [下载管理](Downloads)）。
  - 原图下载完成后，旧的重采样副本自动删除（页数一致才删；目录只读删除失败时会提示手动删除，任务不受影响）。

## 阅读器（`#/reader/<id>/<page>）`

- 逐页流式加载。用 **←/→ 方向键**、**空格**或**点击图片**翻页。
- **精准跳页**：顶部工具栏显示页码输入框（支持直接输入数字回车跳转），全屏或阅读中按 **`G` 键**即可聚焦跳页输入框或唤起跳页弹窗。
- **多阅读模式切换（LTR / RTL 日漫 / 双页并排 / 条漫）**：工具栏「模式」按钮可在**顺序 (LTR)**、**日漫 (RTL)**、**双页并排**、**双页日漫**与**条漫 (Webtoon)** 间切换，偏好自动持久化。RTL 模式下翻页按键与点击方向智能反转；双页模式在宽屏下自动将成对页面并排展示（封面单页居中）。条漫为垂直连续滚动（图片 `lazy` 加载），滚动位置写入阅读进度；不使用左右点击/方向键翻页或双页拼版，工具栏仍可 `G` 跳页并返回详情。
- **移动端手势**：支持移动端双击局部缩放（2.2x）及双指捏合缩放（Pinch-to-zoom）。
- **翻过最后一页自动跳转下一画廊**。
- 预加载后三页（双页模式预加载后四页），翻页即时。
- **页面原图浏览器缓存 1 小时**：返回上一页或重复阅读同一画廊直接复用浏览器缓存，不重复下载；缩略图缓存 24 小时。
- 进度条显示 `页 / 总页 · 大小`（自适应 B/KB/MB/GB）。
- 阅读位置自动保存。
- **全屏按钮（或按 `F`）进入图片全屏**：仅图片铺满屏幕（等比 `object-fit: contain`，黑色背景），阅读器工具栏与翻页按钮隐藏；全屏期间翻页（方向键 / 空格 / 点击图片）就地换图、**保持全屏不退出**；翻过末页/回首页自动退出全屏再跳转。`Esc` 退出并恢复原先的「适应」模式、把 URL 同步到当前页。
- **适应模式切换**：阅读器工具栏的「适应」按钮在几种显示模式间切换（默认按页面宽度缩放），对不同长宽比页面更友好；退出全屏后恢复进入全屏前的模式。
- 从画廊库搜索进入的画廊，**阅读器内全程保留搜索上下文**：翻页（方向键 / 空格 / 点击图片 / 点缩略图 / 自动跳下一本）后，左上角「← 详情」与详情页的「← 画廊库」仍带当前搜索关键词与标签筛选，不会回到未筛选的画廊库。
