# 画廊详情与阅读

> 中文 · [English](Reading-EN) | 属于 [使用指南](Usage) 系列

本文档介绍 GalleryVault 的画廊详情信息展示、元数据同步操作以及网页端阅读器特性。

## 画廊详情（`#/gallery/<id>`）

- 展示元数据（大小、自适应单位）、标签与页面缩略图。
- 页面缩略图按页码分页，**每页默认 30 张**（可切换 5/30/50/100/200/500），**选择会被记住**，读完返回后保持。
- **缩略图分页自动定位到阅读位置**：无显式 `?page=` 参数时，缩略图停在阅读进度所在的页码分页（从阅读器返回即回到刚看的那页附近）；手动翻过缩略图页（URL 带 `?page=`）则以它为准。
- **点击标签**可跳转到画廊库，把该标签**追加**进当前筛选（继续叠加可多标签组合）。
- **开始阅读与幻灯片自动播放**：点击「开始阅读」打开阅读器（定位到上次阅读位置）；顶部操作栏同时提供「▶ 幻灯片」及播放间隔设置（秒），点击后直接以幻灯片轮播模式进入阅读器自动翻页。
- **导出 CBZ**：把当前画廊打成 CBZ 下载。库里已是 `.cbz` 的直接给出原文件；目录画廊按页序打包（不改落盘格式）。
- **打开原站**：新标签页跳转到 ExHentai 上对应的画廊页，链接按设置里的 base URL 生成（`{base}/g/{gid}/{token}/`），需浏览器已登录 EH；本地无 token 的画廊不显示此按钮。
- **同步标签**：从 ExHentai 拉取该画廊标签/元数据；收藏夹已缓存时直接复用缓存（免网络）。
- 使用**外站（e-hentai.org）**时，里站专属画廊会**暂停**标签同步（不会被误判为已删除、分类不受影响），在设置里切回 `exhentai.org` 后自动恢复。
- **本地星级 / 笔记 / 自定义标签**：收在「更多」操作按钮后，详情页可打 1–5 星、写笔记、加 `local:` 标签（不覆盖 EH 标签；标签同步会保留 `local:`）。库可按本地星级筛选。
- 画廊属于哪些收藏夹会以徽标显示；未收藏画廊支持**加入收藏**（选择 0~9 号收藏夹弹窗，云端成功后写入本地并迁出其它夹），已收藏画廊支持**更改收藏夹**（Move）与**取消收藏**，且严格以 ExHentai 云端成功为前提同步本地。**收藏备注**可编辑（走 EH applyfav / `favnote`，云端成功才写本地）；收藏夹列表会显示备注。
- **原图 / 重采样**：收藏夹徽标旁显示本地副本的画质（原图 / 重采样），画质未知时不显示。画质在下载时记录，存量画廊通过「本地文件大小 vs ExHentai 原图大小」推断——收藏夹同步（轮询 / 立即检查 / 拉取缺少项目）与**扫描库**完成时自动补齐。
- **升级为原图**：非原图且有 ExHentai gid 的画廊，工具栏显示两个按钮——
  - **下载原图**：逐张下载原图（不耗 GP，进度见下载页）；画廊在 ExHentai 上无原图时不会入队。
  - **归档形式下载原图**：弹出费用/余额预览（锁定原图档，原图不可用或 GP 不足时禁用），走 ExHentai 归档（zip）通道（详见 [下载管理](Downloads)）。
  - 原图下载完成后，旧的重采样副本自动删除（页数一致才删；目录只读删除失败时会提示手动删除，任务不受影响）。

## 阅读器（`#/reader/<id>/<page>`）

- 逐页流式加载。用 **←/→ 方向键**、**空格**或**点击阅读区左右半边**翻页（条漫模式除外，见下）。
- **快捷键速查**：
  | 快捷键 | 作用 | 备注 |
  |---|---|---|
  | `←` / `→` | 上一页 / 下一页 | RTL 日漫模式下方向自动反转；条漫模式无效 |
  | `Space` (空格) | 下一页 | 条漫模式无效 |
  | `G` | 聚焦跳页输入框 / 弹窗跳页 | 支持全屏或无工具栏时直接唤起跳页 |
  | `F` | 进入 / 退出图片全屏 | 翻页就地平滑换图，保持全屏不退出 |
  | `Esc` | 退出全屏 | 浏览器原生退出全屏；同时停止幻灯片，并恢复进入全屏前的阅读器样式 |
- **移动端触控手势**（条漫模式不使用左右点击与缩放手势）：
  - **点击左右两侧**：左侧上一页、右侧下一页（RTL 模式智能反转翻页方向）。
  - **双击缩放 (Double-tap)**：以触击位置为锚点迅速放大至 2.2x 局部细节；再次双击恢复原始比例。
  - **双指捏合缩放 (Pinch-to-zoom)**：支持 1.0x ~ 3.5x 平滑连续缩放；放大后需再次双击复位（捏合回到约 1x 时也会复位）。
- **精准跳页**：顶部工具栏显示页码输入框（1 起计，回车跳转），全屏或阅读中按 **`G` 键**即可聚焦跳页输入框或唤起跳页弹窗。
- **多阅读模式切换（LTR / RTL 日漫 / 双页并排 / 条漫）**：工具栏「模式」按钮可在**顺序 (LTR)**、**日漫 (RTL)**、**双页并排**、**双页日漫**与**条漫 (Webtoon)** 间切换，偏好自动持久化。RTL 模式下翻页按键与点击方向智能反转；双页模式在宽屏下自动将成对页面并排展示（封面单页居中）。条漫为垂直连续滚动（图片 `lazy` 加载），滚动位置写入阅读进度；不使用左右点击/方向键翻页或双页拼版，工具栏仍可 `G` 跳页并返回详情。
- **动图自适应幻灯片（Slideshow）**：
  - 工具栏提供「▶」启动按钮与播放间隔输入框（默认 5 秒，自定义值持久化到本地存储 `gv_slideshow_interval`）。点击 ▶ 会把间隔写入 URL（`?slideshow=<秒>`）、**自动进入图片全屏**并开始轮播。按钮不是播放/暂停切换（始终显示 ▶）；全屏后工具栏隐藏，**退出全屏（`Esc` 或全屏按钮）会停止幻灯片**。
  - **动图时长探测**：当前页的类型含 GIF 或 WebP 时，阅读器请求 `GET /api/galleries/{id}/pages/{page}/meta`，读取各帧 delay 之和 `duration_ms`（不返回帧率）。轮播延迟为 `max(用户设定间隔, duration_ms + 150ms)`，保证至少完整播放一轮。切页前用 `img.decode()` 预解码，过期的切页请求会被丢弃。
  - 手动翻页或点击左右热区会取消当前计时并按新页重新调度（不暂停）。改间隔输入框不会立刻生效，需再点 ▶。条漫模式无幻灯片控件。翻过末页会先停止幻灯片并退出全屏，再跳转下一画廊（不会连播）。
- **翻过最后一页自动跳转下一画廊**（已在首页时再往前翻不会退出全屏、也不会跳上一本）。
- 进入阅读器时预加载后三页（双页模式后四页）；翻页后再预载后续 1～2 页。
- **浏览器缓存**：页面原图接口未设 `Cache-Control`（由浏览器默认处理）；缩略图封面 `max-age=86400`（24 小时），其余页缩略图 `max-age=31536000, immutable`（约 1 年）。
- 进度条：单页显示 `页 / 总页 · 大小`（自适应 B/KB/MB/GB）；双页显示 `左-右 / 总页`（不带大小）。
- 阅读位置自动保存。
- **全屏按钮（或按 `F`）进入图片全屏**：仅图片铺满屏幕（等比 `object-fit: contain`，黑色背景），阅读器工具栏与翻页按钮隐藏；全屏期间翻页（方向键 / 空格 / 点击热区）就地换图、**保持全屏不退出**；翻过末页自动退出全屏再跳下一本。`Esc` 退出全屏并同步 URL。
- **适应模式切换**：工具栏「适应」在默认（限制最大高度约 82vh）与铺满页宽两档间切换；退出全屏后恢复进入全屏前的阅读器样式。
- 从画廊库搜索进入的画廊，**阅读器内全程保留搜索上下文**：翻页（方向键 / 空格 / 点击热区 / 点缩略图 / 自动跳下一本）后，左上角「← 详情」与详情页的「← 画廊库」仍带当前搜索关键词与标签筛选，不会回到未筛选的画廊库。
