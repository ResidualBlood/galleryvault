# 画廊详情与阅读

> 中文 · [English](Reading-EN) | 属于 [使用指南](Usage) 系列

画廊详情、标签同步与网页阅读器。

## 画廊详情（`#/gallery/<id>`）

### 页面信息与操作入口

| 入口／区域 | 说明与支持操作 | 交互结果与限制 |
| :--- | :--- | :--- |
| **元数据与标签** | 展示画廊大小（自适应单位）、分类、标签及页面缩略图。点击标签可跳转画廊库并追加到当前筛选条件（语法见 [画廊库](Library)）。若画廊包含 `uploader` 命名空间标签，该分组固定排列在全部标签分组最末尾；无上传者时不显示。 | 仅展示本地已有信息。详情页默认读取本地数据库，不主动发起远程网络请求。 |
| **缩略图列表** | 默认每页 30 张（可在 5 / 30 / 50 / 100 / 200 / 500 之间切换，选择自动持久化）。支持无限滚动加载（约 5 批后出现手动「加载更多」按钮），底部分页器同步可用。 | 打开时自动定位至上次阅读进度所在批次；若 URL 带 `?page=` 参数，则以参数指定的批次为准。 |
| **阅读与幻灯片** | 点击「开始阅读」进入阅读器并定位到上次阅读位置。顶部提供「▶ 幻灯片」及播放间隔（秒），点击后直接以幻灯片模式进入阅读器并全屏自动翻页。 | 偏好与进度自动记录；条漫模式不提供幻灯片控件。 |
| **CBZ 导出** | 点击「导出 CBZ」将画廊整体打包下载。 | 磁盘中已是 `.cbz` 文件的直接提供原件；目录画廊按页序实时打包流式输出，不改写磁盘现有结构。 |
| **原站直达** | 点击「打开原站」在新标签页跳转到 ExHentai 画廊页（`{base}/g/{gid}/{token}/`）。 | 浏览器须已登录 ExHentai 账号；本地未存储 token 的画廊不显示该按钮。 |
| **标签同步** | 显式点击「同步标签」（`POST /api/galleries/{identifier}/sync-tags`）或后台任务触发元数据同步。 | 若本地元数据缓存已包含标签，直接复用缓存；外站镜像（e-hentai.org）下里站专属画廊会自动暂停同步，切回 exhentai.org 后恢复。 |
| **本地标注与收藏** | 「更多」菜单内支持设置 1–5 星本地评分、编辑本地笔记、添加 `local:` 前缀自定义标签（标签同步不会覆盖 `local:` 标签）。支持查看所属收藏夹徽标。 | 未收藏画廊支持加入收藏（0–9 号文件夹），已收藏画廊支持移动与取消收藏；编辑收藏备注及状态变更均以 ExHentai 云端确认成功为前提更新本地。 |
| **画质与升级原图** | 收藏夹徽标旁标注本地副本画质（原图 / 重采样）。非原图且具备 ExHentai gid 的画廊，工具栏提供「下载原图」（逐页拉取，不耗 GP）与「归档形式下载原图」（zip 整包通道，消耗 GP，详见 [下载管理](Downloads)）。 | 下载完成后自动删除旧的重采样副本（仅在页数一致时删除；若存储目录为只读导致删除失败，会提示手动删除，下载任务本身不受影响）。 |

### uploader 获取与补全机制

- **来源与队列**：后台任务在服务启动及新画廊入库时扫描未同步画廊，自动加入同步队列。
- **自动补全**：优先复用本地元数据缓存；无缓存或强制同步时调用批量 gdata 接口，失败或字段不完整时回退解析画廊网页。
- **标签使用**：获取上传者后写入画廊记录并建立 `namespace="uploader"` 标签；画廊库支持通过 `uploader:"..."` 精确匹配或 `uploader:name*` 前缀匹配进行检索，详见 [画廊库](Library)。

## 阅读器（`#/reader/<id>/<page>`）

### 阅读模式与快捷操作

阅读器采用逐页流式加载，支持多种排版与交互控制：

| 模式 | 翻页操作 | 显示特性与差异 |
| :--- | :--- | :--- |
| **顺序 (LTR)** | `←` 上一页，`→` / `Space` 下一页；点击阅读区左/右半边 | 单页自适应居中，适合常规阅读顺序。 |
| **日漫 (RTL)** | `→` 上一页，`←` / `Space` 下一页；点击阅读区右侧上一页、左侧下一页 | 键盘与屏幕左右触控翻页方向反转。 |
| **双页并排** | 同 LTR 翻页操作 | 宽屏下两页并排显示，第 1 页作为封面单独居中。进度显示 `左-右 / 总页`。 |
| **双页日漫** | 同 RTL 翻页操作 | 宽屏下两页并排且顺序自右向左，第 1 页作为封面单独居中。 |
| **条漫 (Webtoon)** | 垂直平滑滚动；不支持左右点击翻页、空格翻页与双页拼版 | 垂直连续排列，图片延迟加载 (`loading="lazy"`)。滚动位置实时写入阅读进度；仍支持 `G` 键跳页。 |

**快捷键对照表**：

| 快捷键 | 作用 | 备注与限制 |
| :--- | :--- | :--- |
| `←` / `→` | 切换上一页 / 下一页 | RTL 日漫模式下方向自动反转；条漫模式下无效。 |
| `Space` | 切换下一页 | 条漫模式下无效。 |
| `G` | 聚焦跳页输入框 / 打开跳页弹窗 | 支持在全屏或工具栏隐藏状态下直接唤起页码跳转。 |
| `F` | 进入 / 退出图片全屏 | 就地切换图片，翻页保持全屏状态不退出。 |
| `Esc` | 退出全屏 | 退出全屏状态；若正在播放幻灯片则一并停止，并恢复全屏前的阅读器排版。 |

**移动端手势对照表**：

| 手势 | 操作与效果 | 限制与复位 |
| :--- | :--- | :--- |
| **左右侧触击** | 点击屏幕左侧上一页、右侧下一页（日漫模式翻页方向反转） | 条漫模式不生效 |
| **双击缩放** | 以触击位置为中心快速放大至 2.2 倍局部细节；再次双击恢复原始比例 | 条漫模式不生效 |
| **双指捏合缩放** | 支持 1.0 倍至 3.5 倍连续缩放 | 捏合或双击回到接近 1.0 倍时自动复位；条漫模式不生效 |

### 幻灯片自动播放与展示控制

- **启动与控制**：工具栏提供「▶」按钮与间隔输入框（默认 5 秒，配置项持久化保存于 `gv_slideshow_interval`）。点击启动后将间隔参数写入 URL（`?slideshow=<秒>`），自动进入图片全屏并开始轮播。全屏状态下隐藏工具栏，按 `Esc` 键或点击全屏控件退出全屏即停止播放。
- **动图时长探测**：当前页面为 GIF 或 WebP 格式时，阅读器请求单页元数据接口获取各帧延迟之和（`duration_ms`，扫描整轮，上限 120 秒）。播放间隔采用 `max(设定间隔, duration_ms + 150ms)`；切页前执行预解码。
- **调度与翻页边界**：手动翻页或点击热区会重置当前倒计时并按新页面重新调度；修改间隔输入框需重新点击「▶」生效。翻过最后一页自动停止幻灯片并退出全屏，然后跳转至下一画廊（不连续自动播放）。在第一页向前翻页不退出全屏且不跳转至上一本。
- **预载与缓存**：打开阅读器预载后续 3 页（双页模式预载 4 页），翻页后再预载 1–2 页。封面缩略图缓存 24 小时，其余页缩略图长期缓存；原图由浏览器默认缓存管理。
- **排版适应与搜索上下文**：工具栏「适应」按钮可在默认最大高度（约 82vh）与铺满页宽之间切换。从画廊库搜索进入阅读器后，翻页、点击缩略图或跳转下一本均保留当前搜索关键字与标签筛选条件。
