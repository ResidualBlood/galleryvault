# 系统设置

> 中文 · [English](Settings-EN) | 属于 [使用指南](Usage) 系列

系统设置、OPDS、Telegram Bot，以及哪些操作需要访问网络。

## 设置（`#/settings`）

### 账户与界面

| 设置项 | 字段 / 取值 | 说明与默认值 |
| :--- | :--- | :--- |
| 修改密码 | - | 修改密码后撤销所有已登录会话。 |
| 需要登录 | 开关 | 切换是否启用登录认证。 |
| 会话时长 | `galleryvault_session`<br>`galleryvault_csrf` | Web 会话与 CSRF Cookie 默认有效时长为 10 年（`315360000` 秒）；修改密码或重置签名密钥后所有现存会话立即失效。 |
| 标题显示 | `japanese`<br>`english`<br>`directory` | 画廊库、浏览、详情、收藏夹、收藏查重与副本去重页标题显示策略。默认 `japanese`（日文优先，无日文回退英文）。 |
| 界面主题 | `gv_theme` | 顶栏 ◐ 图标切换浅色或深色主题，持久化于本地存储，默认深色（`dark`）。 |

### 站点与代理

| 设置项 | 参数 / 字段 | 说明与默认值 |
| :--- | :--- | :--- |
| ExHentai 基础 URL | `exhentai_base_url` | 仅支持 `exhentai.org` / `e-hentai.org` 或其子域。 |
| Cookie 认证 | `ipb_member_id`<br>`ipb_pass_hash`<br>`igneous` | 配置后通过「测试登录」验证，Cookie 字段不回显。具体获取与配置流程请参阅 [入门向导与 Cookie 配置](Usage#配置-exhentai-cookie)。 |
| 连通性探活 | 周期探活 | 启动时探活，之后每 30 分钟检查一次；Cookie 失效、无里站权限或 IP 封禁显示红条，网络失败显示橙条，均链接至设置页。 |
| 网络代理 | HTTP / SOCKS5 | 二选一配置代理服务器地址与端口。 |

### 资料库与存储

| 设置项 | 参数 / 取值 | 说明与约束 |
| :--- | :--- | :--- |
| 库根目录 | 路径列表 | 每行一个文件系统路径，默认包含 `/library` 与 `/downloads`。扫库覆盖全部路径；删除画廊时若挂载可写则一并删除对应文件，若为只读挂载则删除失败并在提示与日志页报错。 |
| 冷存储归档 | `archive_roots` | 多行文件系统路径（如 `/archive`）。留空表示不启用；旧配置 `cold_storage_root` 自动转为单项列表。默认不自动归档、归档后不删除源文件。详细挂载与容量均衡规则请参阅 [部署指南 → 冷热分层存储](Deployment#2-冷热分层存储多盘挂载与归档规则)。 |
| 冷归档规格 | 限制规格 | 单卷上限 **500 页且 2GiB**（两者取 AND），超限时生成冷目录而非单卷 CBZ。CBZ 路径为 `{cold}/cbz/{hh}/{ii}/{gid}-{DB 英文标题}.cbz`，内部包含 `.galleryvault.json`。操作入口位于 **管理 → 冷库归档**（`#/archive`）。 |
| 清理残留 | 存储操作 | 设置页存储表提供「清理已归档源目录残留文件」，自动跳过处于 pending 或 downloading 状态的任务。 |
| 磁盘用量表 | 监控指标 | 显示 library、cold、downloads、cache 四行路径、条目数、已用空间与磁盘剩余；列出体积最大的 10 本画廊。打开设置页不扫描全盘。 |
| 压缩包与文档 | `.7z` / `.pdf` | 识别 `.7z`（只收图，阅读时内存解压，单页解压上限 128MB）与 `.pdf`（抽取内嵌图片，单图超过 128MB 或抽取失败则跳过）。 |

### 下载常用与高级选项

**下载常用配置**：

| 设置项 | 参数 / 取值 | 说明与默认值 |
| :--- | :--- | :--- |
| 下载根目录 | `download_root` | 新增下载任务写入的目标热目录。 |
| 并发画廊数 | 数值 | 同时进行下载的画廊任务数量上限。 |
| 单画廊并发页数 | 数值 | 单个画廊同时拉取图片的并发数，默认 `4`。H@H 节点对单 IP 并发有限，若线路不稳定设过高易出现连接错误。 |
| 下载画质 | 普通 / 原图 | 默认下载图片画质。 |
| 归档下载质量 | 默认档位 | 官方整包归档通道的默认请求画质。 |
| 归档降级为逐页 | 开关 | 默认开启。当官方归档通道无法提供服务时，自动转为逐页下载，不扣除 GP。 |

**下载标题命名与高级选项**：

- **下载标题命名**：仅控制下载热目录 `download_root` 新建文件夹命名——`japanese`（默认，`gid-日文标题`，无日文标题时回退英文）或 `english`（`gid-英文标题`）。与界面的「标题显示」相互独立（冷库 CBZ 固定使用数据库英文标题，不受此项影响）；已下载画廊复用原有目录，切换设置不会改名或重复下载。
- **高级选项（折叠）**：
  - H@H 开关与归档默认画质。
  - `favorites_archive_max_pages`：收藏夹归档页数阈值，`0` 表示全部。
  - 定时扫描大画廊走归档。
  - 慢速 H@H 看门狗：配置单图最大耗时、预热窗口与最低 KB/s 速率。
  - 302 探针间隔：环境变量 `GV_CHALLENGE_PROBE_INTERVAL`（默认 600 秒）。

### 标签与缩略图

| 设置项 | 字段 / 操作 | 说明与行为 |
| :--- | :--- | :--- |
| 标签自动同步 | 开关 / 间隔 / 并发 | 扫描或启动后自动同步标签元数据；提供「立即同步标签」操作。 |

| 缩略图生成 | 开关 / 操作 | 自动生成开关与「立即生成」操作，显示实时状态；后台定期巡检补齐新画廊缩略图，并清理数据库中已无记录的孤立缩略图缓存。 |

### OPDS 与 PWA

| 功能 | 协议 / 路径 | 认证方式与行为 |
| :--- | :--- | :--- |
| OPDS 目录 | `GET /api/opds` | 返回最近入库最多 50 条画廊（Atom XML 格式），条目 acquisition 指向 `GET /api/galleries/{id}/export.cbz`。 |
| OPDS 认证 | HTTP Basic | 支持 HTTP Basic 认证，用户名固定为 `galleryvault`（非 EH 账号），密码为本系统 Web 登录密码；亦支持 Cookie 鉴权。未提供凭据或认证失败返回 `401 Unauthorized` 并附带 `WWW-Authenticate: Basic realm="GalleryVault OPDS"` 响应头。 |
| CBZ 导出 | 导出 API | 实际 CBZ 导出及常规 `/api/*` 请求均仅支持基于 Cookie 的登录会话。 |
| PWA 离线支持 | Service Worker | 支持添加到主屏幕。仅缓存 HTML、CSS 与 JS 壳（静态资源采用 network-first 策略，成功后写入缓存；离线时回退到缓存）。明确不缓存画廊图片与 `/api/` 接口响应。 |

### Telegram Bot 配置与命令

**Bot 配置**：

- **基础配置**：配置 bot token、chat ID 与允许的 user ID，提供「发送测试消息」验证连通性。配置 token 后启动会自动向 Telegram 注册客户端指令菜单。
- **通知选项**：通知级别支持「汇总 / 即时 / 仅失败 / 关闭」；通知语言支持「中文 / English」。下载、扫库、收藏夹检查、302 临时挑战告警（🚨 触发 / ✅ 恢复）与 Bot 回复统一采用该语言。消息使用 Telegram HTML 格式（标题加粗、GID 等宽），画廊标题保持原文不翻译。

**控制命令表**（仅限允许的 user ID；聊天框输入 `/` 可见菜单）：

| 分类 | 命令 | 说明 |
| :--- | :--- | :--- |
| 系统与运维 | `/status`<br>`/ping`<br>`/cookie`<br>`/quota`<br>`/storage`<br>`/scan`<br>`/help` | 查看运行状态与队列概况；测试延迟；检查 Cookie 有效性；查看图像配额与 GP；查看磁盘用量；触发扫库；查看命令说明。 |
| 下载与队列 | `/queue`<br>`/pause`<br>`/resume`<br>`/retry <id/all>`<br>`/cancel <id/gid>`<br>`/clear`<br>`/stats` | 查看队列与操作按键；全局暂停与恢复；重试失败任务；取消任务；清除成功记录；查看库本数与队列快照。 |
| 后台任务 | `/tasks`<br>`/kill <name>` | 查看长任务列表；中断指定任务。 |
| 图库 | `/search <关键词>`<br>`/info <gid>`<br>`/random`<br>`/redownload <gid>` | 本地搜索与翻页；查看画廊详情与封面；随机抽取画廊；重新下载指定画廊。 |
| 收藏夹 | `/fav_sync`<br>`/fav_download [0-9]`<br>`/fav_check` | 同步收藏夹分类；下载指定收藏夹未入库项；全量检查收藏夹更新。 |

**全局暂停与 URL 交互**：

- **全局暂停语义**：`/pause` 为全局暂停，持久化于 `app_config.user_settings`，服务重启后依然生效。执行后停止认领新画廊，暂停后不再领取新图片页，已开始的当前页会下载完成；已入队任务不丢失，恢复后继续处理。同时暂停定时自动扫描与 Web 端手动触发的新扫描（触发时返回 `paused`）。Web 下载页暂停按钮与 Bot `/pause` / `/resume` 共用同一控制开关（`GET/POST /api/pause`），顶栏黄条与 Cookie 红条可叠加显示。
- **画廊 URL 粘贴入队**：直接在聊天框粘贴画廊 URL（例如 `https://exhentai.org/g/2325283/d3722b6aa8/`）会自动解析 GID 与 token 并在未暂停状态下立即加入下载队列，Bot 回复确认消息与画廊标题（若检测到新版会提示旧新 GID 变更；若 404 或画廊已删除则提示未入队）。全局暂停期间粘贴的 URL 会被忽略且不入队。发送其他非 URL 文本回复 `/help`。

## 哪些操作要上网

| 网络对象 | 操作 | 条件与行为 |
| :--- | :--- | :--- |
| **ExHentai / E-Hentai 源站** | 发现页与在线搜索 | 访问普通搜索、热门、关注与排行榜；包含后端短期结果缓存（60s / 120s）。 |
| | 普通分页下载 | 并发受限，原图与普通请求分别控制，通过 H@H 节点拉取。 |
| | 官方归档整包下载 | 扣除 GP 或配额，直接拉取源站打包文件。 |
| | 标签与元数据同步 | 批量调用 gdata 接口拉取元数据、在线分类与画质探测信息。 |
| | 收藏夹双向管理 | 定期拉取云端分类、数量与列表；向云端提交添加、移除、移动分类或备注修改。 |
| | Cookie 探活与配额检查 | 启动及每 30 分钟周期探活；反爬阻断（Challenge / 509）后自动探活恢复；查询 GP 与图像配额。 |
| | 画廊新版本下载 | 一键更新创建新下载任务时，拉取新 GID 的画廊数据。 |
| **GitHub API (`api.github.com`)** | EhTag 翻译词库 | 检查并拉取 EhTag 数据库更新。 |
| **Telegram Bot API (`api.telegram.org`)** | 推送通知与交互 | 推送通知与 Bot 长轮询交互（需配置 Bot Token）。 |
| **纯本地离线（不访问外网）** | 画廊详情与阅读 | 详情页读取本地数据库，阅读器仅加载本地文件，完全不向源站发起请求。 |
| | 库维护与冷库归档 | 扫描本地磁盘入库、CBZ 冷库打包与源文件清理、OPDS 目录与 CBZ 导出、回收站操作。 |
| | 收藏夹更新初筛 | 基于本地已有记录和标题做文本匹配初筛，不发起外网请求。 |
| | 本地分类修复 | 依据本地 `.galleryvault.json` 标签重推大类，不访问外网。 |
| **本地优先缓存例外** | 详情与入队准备 | 详情优先读取本地数据库；下载入队准备优先复用本地元数据，缺失时才请求 gdata。 |
| | 封面与配额缓存 | 获取远程封面先查本地缓存目录，无本地文件才发外网请求；GP 与配额在缓存有效期内不重复请求源站。 |
| | PWA 资源缓存 | Service Worker 仅缓存静态 HTML/CSS/JS 资源（采用 network-first 策略）；明确不缓存画廊图片与 `/api/` 接口响应。 |
