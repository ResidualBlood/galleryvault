## 核心专精与架构设计

GalleryVault 并非通用型电子书工具，而是专门针对画廊数字资产、高保真元数据体系与分布式同步需求打造的私有归档系统。

```
┌─────────────────────────────────────────────────────────────┐
│                      Web 前端 (Vanilla SPA)                  │
│   画廊资产库  ·  多维标签云  ·  收藏夹监控  ·  版本更新追踪  ·  阅读器  │
└──────────────┬───────────────────────────────▲──────────────┘
               │ HTTP / JSON API (:8000)       │
┌──────────────▼───────────────────────────────┴──────────────┐
│                    FastAPI 核心服务 (:8001)                  │
│  ┌────────────────────────┐   ┌───────────────────────────┐ │
│  │    存储与元数据解析     │   │     细粒度调度与下载引擎    │ │
│  │ Ehviewer/Sidecar/CBZ   │   │  并发流控 / 慢速看门狗 /   │ │
│  │ 跨 GID 聚类与查重治理  │   │  Range续传 / 302 自愈探针 │ │
│  └───────────┬────────────┘   └─────────────┬─────────────┘ │
│              │                              │               │
│  ┌───────────▼──────────────────────────────▼─────────────┐ │
│  │                状态机与持久化存储 (PostgreSQL)            │ │
│  │      AES-256-GCM 静态加密 (可选) · 10 年持久化会话     │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

## 详细功能矩阵

### 1. 本地画廊资产管理与高保真解析
- **Ehviewer 目录零侵入直读**：扫描原生 `<gid>-<标题>/` 目录结构，自动解析 `.ehviewer` 元数据（SpiderInfo V1 与 V2），精准恢复 gid、token、画廊分类与各页索引，无需解压或重构文件夹。
- **多元归档格式支持**：全面兼容 CBZ、CBR 压缩包（内嵌 `ComicInfo.xml`）、JHenTai `metadata` JSON，以及分层冷存储归档中的 `.galleryvault.json` sidecar 索引文件。
- **纯图片与免解压解析**：对 `.7z` 归档包仅提取图片数据流，杜绝磁盘垃圾碎片；对缺乏 gid 的纯画廊提供本地浏览与星级标记能力。
- **冷热分层存储架构**：支持将新下载的活跃工作区（热存储）与只读归档硬盘（冷存储）解耦挂载，支持随时按需向冷库迁移归档。
- **本地画廊自定义组织**：支持基于本地自定义列表、星级评分与私有阅读笔记进行个性化分类管理，完全独立于外部站点。

### 2. 智能生命周期追踪与副本治理
- **重传版本自动检测（Updates）**：自动化比对云端画廊重传或版本更迭事件（识别云端重新发布分配的新 GID），支持一键下载最新版并自动清理本地旧版残余。
- **收藏夹跨 GID 智能聚类查重**：针对不同汉化组、不同压制画质或多次重复收藏，基于作品特征进行跨 GID 智能聚类，直观呈现对比差异，支持一键移除重复项。
- **同 GID 多副本清理策略**：当同一画廊因多盘挂载或路径重复入库时，根据预设策略（保留已有/页数多/体积大/最新或手动）自动治理，避免磁盘空间浪费。
- **标题多模式渲染**：全站支持「日文原生 / 英文 / 目录名」三档独立显示切换，且与下载目录的命名规则彻底解耦。

### 3. 云端元数据深度联动
- **元数据批量缓存（gdata）**：使用自有凭证高效拉取画廊分类、详细标签及评分，内置智能缓存池避免高频重复请求。
- **10 个收藏夹独立监控**：支持为每个收藏夹独立配置「增量下载」、「仅监控」或「定时轮询」模式，自动检测新加入项目并排队下载。
- **多站点自适应兼容**：支持在 `exhentai.org`、`e-hentai.org` 与自定义反代域名之间自由切换；在表站模式下自动安全暂停里站专属条目的标签同步，杜绝误判误删。
- **凭据状态实时探活**：系统启动及周期性后台自动探活凭证有效性，顶栏即时直观提示状态并引导维护，避免下载因静默失效而中断。
- **发现页在线探索（Discover）**：在 Web 界面直观浏览热门、关注与榜单，支持一键入库或同步至云端收藏。

### 4. 稳健的并发调度流水线与自愈机制
- **双模下载引擎**：
  - **分页并发流式下载**：细粒度并发控制、实时进度看板与单页断点续传（仅补全缺失页）。
  - **官方整包归档下载**：支持官方 Zip 归档通道，通过 GP 配额换取极速打包，支持单连接流式传输与 Range 断点续传，且**重试绝不重复扣除 GP**。
- **慢速节点与超时看门狗**：具备单图总超时、预热期与最低传输速率三维看门狗，自动踢除迟钝的 H@H 节点并切换新链路，杜绝单个慢任务卡死整个队列。
- **指数退避故障自愈**：遇到网络瞬时抖动、代理断流或服务端波动时，自动执行指数退避重试（30 秒至 6 小时递增，最多 10 次），无需人工干预。
- **302 防爬挑战静默防护**：检测到服务端 302 临时挑战时，自动挂起下载队列以保护账号凭据，后台探针以可配置周期（默认 10 分钟）静默探活，限制解除后自动无缝恢复。
- **增量即时写入**：下载完成的画廊立即完成元数据入库与封面生成，无需触发全量扫盘。

### 5. 沉浸式阅读与开放生态
- **全模式阅读器**：
  - **阅读排版**：支持从右向左（RTL 日漫模式）、从左向右（LTR）、垂直连续滚动（条漫/瀑布流）以及双页并排阅读。
  - **翻页与导航**：支持键盘快捷键、鼠标滚轮、点击热区、`G` 键快速跳页与预加载机制，末页自动无缝衔接下一画廊。
- **动图自适应幻灯片**：原生解析 GIF、WebP 动图的帧间隔与总时长，自动以精准的原生节奏播放幻灯片，呈现最佳观赏效果。
- **多标签多维组合检索**：深度集成 EhTagTranslation 多语言数据库，支持标签建议、多标签 AND/OR 逻辑组合、`-tag` 排除语法以及中文输入反向联想（例如输入「长发」自动联想 `long hair`）。
- **开放 OPDS 目录协议**：内置标准 OPDS 规范端点（`GET /api/opds`），支持 HTTP Basic 认证，可直接连接 Tachiyomi、Mihon、Panels 等第三方移动端阅读器。
- **完整操作历史与回收站**：用户手动删除或磁盘离线的画廊进入安全回收站，提供全流程操作审计与一键找回。

### 6. 企业级安全加固与高可用运维
- **AES-256-GCM 数据库静态加密**：支持配置 `ENCRYPTION_KEY` 环境变量，自动将数据库中的 Cookie、令牌与密码哈希进行高强度字段级静态加密存储。
- **10 年持久化免登会话**：Web 会话 Cookie 签名密钥自动持久化落库，容器重启或系统升级后无感维持登录态；修改管理员密码可瞬间吊销所有已登录设备凭据。
- **安全隔离与非 root 降权**：支持配置 `PUID` / `PGID` 环境变量实现 NAS 环境安全降权运行；内置严格的 CSRF 防护与反向代理受信网段（`TRUSTED_PROXIES`）白名单校验。
- **开箱即用容器化栈**：多架构 Docker 镜像（AMD64 / ARM64），内置数据库自动化迁移机制（Alembic），单命令部署即用。
