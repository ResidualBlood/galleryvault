# 功能特性

> **中文** · [English](Features-EN)

按功能模块列出 GalleryVault 的主要能力、前置条件与核心限制。系统由前端 SPA、后端 FastAPI 服务与 PostgreSQL 数据库组成，组件拓扑与反向代理配置详见 [部署指南](Deployment)。

---

## 1. 扫描与格式

- **Ehviewer 目录扫描**：支持扫描 `<gid>-<标题>/` 结构并解析 `.ehviewer`（SpiderInfo V2 与 V1），获取 gid、token 与各页 pToken。标题、分类和标签通过目录名、`.galleryvault.json` 或云端 gdata 补全，无需解压或重命名。
- **多元归档格式**：兼容 CBZ、CBR（支持内嵌 `ComicInfo.xml`）、JHenTai 逐页目录 `metadata` JSON 以及冷库 `.galleryvault.json`。
- **7z / PDF / 无 gid 目录**：`.7z` 仅索引图片内容且按页在内存解压；`.pdf` 提取内嵌图像；解压与提取单页体积上限均为 128MB。无 gid 纯图目录支持本地浏览、自定义标签与评分。
- **冷热分层存储**：新下载画廊写入热数据目录；归档根目录支持多盘挂载与容量均衡。归档动作需手动执行，不会静默自动归档。
- **本地化整理**：支持自定义列表、星级评分、阅读进度与本地笔记，完全离线可用。
- **详细参考**：支持矩阵与命名约束参见 [兼容与格式规范](Compatibility)；浏览与本地管理参见 [画廊库与浏览](Library)。

## 2. 版本与查重

- **重传版本检测（Updates）**：检测云端画廊重新上传后分配的新 GID。支持一键下载新版本，并在下载确认成功后安全删除本地旧副本。
- **跨 GID 查重聚类**：根据画廊特征聚类识别不同汉化版本、画质差异或多收藏夹重复收录条目，支持批量对比与清理。
- **同 GID 多副本清理**：当同一画廊因多盘挂载或路径重复入库时，支持按保留规则（已有项目、页数最多、体积最大、最新导入或手动指定）保留一份并清理冗余。
- **标题多档呈现**：支持日文原名、英文译名与本地目录名三档显示切换，与底层下载目录命名解耦。
- **详细参考**：版本检测与收藏查重参见 [收藏夹管理](Favorites)；副本清理与安全删除参见 [库管理与维护](Manage)。

## 3. 站点与收藏

- **元数据同步（gdata）**：使用已配置的站点 Cookie 查询云端分类、标签、评分及上传者信息，查询结果本地缓存。
- **多收藏夹独立管理**：支持 10 个站点收藏夹的分类管理。每个收藏夹可独立设定「增量下载」、「仅监控」或「强制下载」模式与轮询周期，定时检查时按模式入队。
- **合法域名约束**：仅允许解析与请求 `exhentai.org`、`e-hentai.org` 及其子域，其余主机名直接拒绝。表站认证模式下暂停里站专属条目的标签同步。
- **Cookie 状态检测**：服务启动及后台周期性检测 Cookie 连通性与权限，失效时在顶栏显示警告提示。
- **发现页浏览**：内置 Popular、Watched、Toplist 发现页浏览，支持直接入队下载或添加至收藏夹。
- **详细参考**：收藏夹规则与同步详情参见 [收藏夹管理](Favorites)；发现页使用参见 [画廊库与浏览](Library)。

## 4. 下载

- **逐页并发下载**：支持画廊并发数与页面并发数配置，实时显示任务进度与状态徽标；失败重试仅补充下载缺失页面。
- **官方归档整包通道**：支持官方 ZIP 归档下载通道，需消耗账号 GP；采用单连接流式传输与 HTTP Range 断点续传，重试复用任务 URL 不重复扣除 GP（文件损坏重新打包或中途改动画质档位除外）。
- **节点优选与剔除**：具备单图超时保护、预热窗口与最低传输速率检测，自动剔除响应迟缓的 H@H 节点。
- **指数退避重试**：网络瞬时故障按 30 秒至 6 小时阶梯递增重试，单个任务上限重试 10 次；达到上限后任务保持失败，不会自动复活，需手动重试或「重试所有任务」恢复。
- **配额挑战保护**：检测到 HTTP 302 临时挑战时自动暂停队列；后台探针每 10 分钟检测一次，限制解除后自动恢复。HTTP 429/509 按配额限流错误退避重试，并携带服务端 `Retry-After`（缺省 60 秒）。
- **下载直接入库**：下载完成后自动生成本地索引与封面缓存，无需触发全盘重新扫描。
- **详细参考**：任务操作、状态徽标与归档边界参见 [下载管理与归档](Downloads)。

## 5. 阅读与检索

- **多排版阅读模式**：支持从右向左（RTL）、从左向右（LTR）、垂直条漫以及双页排版模式。
- **导航与快捷操作**：支持键盘快捷键、屏幕点击热区翻页、`G` 键精准跳转与后台预加载。条漫模式使用滚轮或触控滚动，禁用横向翻页。
- **动画幻灯片播放**：支持 GIF 与 WebP 动图的帧时长分析，单图时长分析上限 120 秒，按动图时长自动匹配播放间隔；全屏启动，退出全屏自动停止。
- **高级标签检索**：内置 EhTagTranslation 中文词库；支持标签自动联想建议、AND/OR 逻辑组合、`-tag` 排除语法及中文反向联想英文标签。
- **OPDS 电子书源**：提供 `GET /api/opds` 目录端点及 `GET/HEAD /api/galleries/{id}/export.cbz` 获取端点，两者均支持 HTTP Basic 认证（未认证返回 401 并附带 `WWW-Authenticate: Basic`），兼容 Tachiyomi、Mihon、Panels 等阅读客户端。
- **安全删除与回收站**：手动删除或扫描丢失的画廊移入回收站保护目录，支持按需还原或彻底清理。
- **详细参考**：阅读器配置与快捷键参见 [画廊详情与阅读](Reading)；检索语法参见 [画廊库与浏览](Library)；回收站机制参见 [库管理与维护](Manage)。

## 6. 安全与部署

- **数据静态加密**：配置 `ENCRYPTION_KEY` 后，系统使用 AES-256-GCM 算法对站点 Cookie、Token 及敏感凭据进行加密存储。
- **持久化安全会话**：会话签名密钥持久化至数据库，服务重启保持登录状态；修改密码自动撤销全部现有会话。
- **权限与代理加固**：支持设置 `PUID` 与 `PGID` 降权运行；内置严格的 CSRF 防护；支持通过 `TRUSTED_PROXIES` 配置反向代理信任网段；压缩包单页解压上限 128MB 防范解压资源耗尽。
- **认证与设置加固**：登录失败按管理员账号指数退避（5 次起，最长 15 分钟）并返回 `429` + `Retry-After`；修改需要登录、可信代理、下载根目录、库根目录等安全敏感设置需当前管理员密码或显式确认（API 返回 `428`）；API 响应附带 `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy` 与 `CSP frame-ancestors 'none'` 等基线安全响应头。
- **容器化支持**：提供 AMD64 与 ARM64 双架构容器镜像，内置 PostgreSQL 数据库集成与 Alembic 启动自动数据迁移。
- **详细参考**：完整部署、网络与反代拓扑参见 [部署指南](Deployment)；密钥安全与灾备参见 [静态加密与密钥](Encryption)。

## 7. Telegram Bot

- **系统通知与集成**：配置 Bot Token 后自动向 Telegram 注册指令菜单，消息通知语言与系统全局语言保持一致。
- **快捷下载与任务管理**：聊天中直接发送画廊 URL 即可解析入队；提供 `/queue` 交互式键盘管理任务状态；`/pause` 与 `/resume` 指令与 Web 端下载总开关实时联动。
- **系统状态远程监控**：支持通过 `/status`、`/storage`、`/quota`、`/cookie` 实时查询下载进度、磁盘剩余空间、GP 额度与 Cookie 状态。
- **库检索与远程维护**：支持 `/search` 翻页检索、`/info` 与 `/random` 推送详情与封面（复用 5 级封面降级逻辑）、`/scan` 触发扫库以及 `/fav_sync`、`/fav_download`、`/fav_check` 远程操作收藏夹。
- **详细参考**：Bot 配置项、命令列表与权限限制参见 [系统设置](Settings#telegram-bot-控制命令)。
