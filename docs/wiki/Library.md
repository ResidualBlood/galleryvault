# 浏览与画廊库

> 中文 · [English](Library-EN) | 属于 [使用指南](Usage) 系列

本文档介绍 GalleryVault 的画廊浏览、发现、主画廊库筛选、本地列表归档、标签系统与阅读历史。

## 浏览（`#/browse`）

- 默认落地页（空 hash / 未指定路由也到此）：按最新发布倒序展示画廊网格，页码分页。
- **继续阅读卡片区**：顶部自动聚合最近阅读的画廊，展示封面缩略图、进度条与百分比；支持一键直达阅读进度或点击 ✕ 标为未读（清除进度并从继续阅读/历史中移除）。
- 顶部有**标签命名空间入口条**（标签 / 作者 / 角色 / 原作 / 社团 / 女性 / 男性 / 语言）与**随机画廊**按钮（🎲，跳转到随机画廊详情页）。
- 顶栏的**全局搜索框**回车即跳转画廊库并执行标题搜索；全站按 **`/` 键**可直接聚焦搜索框。
- 画廊网格支持**键盘方向键导航**（`←`/`→`/`↑`/`↓` 移动焦点，`Enter` 打开详情页）。

## 发现（`#/discover`）

- 在 Web 里逛 / 搜 ExHentai；工具条另有 **Popular / Watched / Toplist**（Toplist：昨日 / 月 / 年 / 总榜，对应原站 `tl=11/12/13/15`）。Watched 未登录走现有 Cookie 错误态。
- 工具条：关键词、分类勾选（按原站 `f_cats` 位掩码）、最低评分、下载画质（默认重采样，可改原图）。
- 卡片：封面、标题、分类、页数、评分；角标可叠加 **已入库 / 已收藏 / 未下载**。
- **下载**走已有 `POST /api/downloads`；**加入收藏**选 0–9 号夹，走 `POST /api/favorites/add`（**仅云端成功才写本地**）。
- 滚动加载下一页，使用站点 `next=gid-ts` 游标，**不用** `page=N`；短缓存避免每次滚回去重打首页。
- 无结果、Sad Panda、空体反爬、509、Cookie 失效**分开提示**，不会当成「没结果」继续翻页。Cookie 失效仍走顶栏红条。

## 系列作品（#/series）

- **自动聚类与活动前缀剥离**：自动识别同人志与漫画系列作品，循环剥离 C100、COMIC1、例大祭等展会与活动前缀进行聚类展示。
- **默认过滤与分页**：默认仅筛选同人志与漫画分类并分页浏览；点击「显示全部」可切换查看包含其他分类的完整系列。
- **云端未下载成员与一键下载**：聚合展示已加入云端收藏但在本地尚未下载的成员作品，显示云端专属角标，并支持一键发起下载补全本地画廊。
- **手工调整与成员调配**：支持通过画廊 GID 或收藏夹快速手工加入系列，支持将误匹配画廊移出云端，并可手工新建组、重命名组、删除组及在组间调配成员。
- **扫库收尾与重新整理**：文件系统扫描（扫库）收尾时自动触发系列重建（rebuild）；亦可在页面直接点击「重新整理」，后台任务进度与结果记录在日志页（`#/logs`）。
- **系列封面**：系列卡片封面复用已有 `GET /api/favorites/cover` 缩略图接口渲染。

## 画廊库（`#/library`）

- 按标题搜索、按分类过滤、多维排序与阅读状态过滤，分页浏览索引的画廊。
- **多维排序**：支持按**入库时间 (默认)**、**发布时间**、**标题**、**页数**、**体积**、**评分**升降序排列，底层建立对应数据库索引，万本库秒级响应。
- **阅读状态筛选**：支持快速筛选**全部**、**未读**、**在读**、**已读完**；三者互斥。未读排除已读完；已读完需真正读过（进度 > 0 且到末页；一页本仅有进度 0 不算已读完）。
- **高级筛选折叠面板**：次要筛选收进可折叠面板，工具栏显示当前激活数量提示；展开后可指定最少/最多页数、最低评分（≥2 / ≥3 / ≥4 / ≥4.5）、体积（MB→字节）、发布日期、上传者子串、画质（原图/重采样）、语言快捷（写入现有 `language:` 标签）、本地星级、本地列表。与排序、阅读状态、标签筛选一并粘性保存。
- **保存的搜索**：把当前筛选存成命名搜索（最多约 30 条，写入设置 `saved_searches`，get+merge 不丢 `auth_secret`）；可应用 / 删除。
- **本地列表**：不依赖 EH。库页/详情可加入或移出；无 gid 的 CBZ 也能进列表；库可按列表筛选（详见下方独立节）。
- **「不在收藏夹」筛选**：分类下拉末尾新增「不在收藏夹」项，只显示本地有、但不在任何 ExHentai 收藏夹里的画廊（无 gid 的本地归档天然属于此类；已被已收藏新版替代的旧画廊会自动排除并归入「更新画廊」）；收藏夹从未同步过时该项等价于「全部」。
- 此页为**无限滚动**：滚动接近底部时自动加载下一页（默认每页 24 个，可在页尾选择页大小）；底部页码分页器保留作兜底。**每页选择会被记住**（浏览器本地保存），阅读往返后仍沿用。
- 点击封面进入画廊详情页（详见 [画廊详情与阅读](Reading)）。
- **多标签筛选（AND / OR）与排除标签（`-tag`）**：
  - 点击标签提示、画廊详情页或标签云中的标签会追加进当前筛选；画廊卡片上的标签支持**普通点击 = 加入筛选**（`ns:name`），**Shift / Alt / Ctrl / Cmd + 点击 = 加入排除筛选**（`-ns:name`，如 `Shift+点击 female:lolicon → -female:lolicon`），卡片内点击已做 `stopPropagation` 不会误触进入详情页；
  - 标签胶囊栏支持点击 **AND / OR** 模式切换；
  - 支持排除标签（输入 `-namespace:name` 或 `-tag`，如 `-female:lolicon`），以红色警示样式显示，匹配画廊将自动排除；排除筛选同样受「删除当前筛选」与粘性上下文保护。
- **标签筛选靠「点击」而非自动猜测**：搜索框输入时会弹出标签建议，**点击建议**才把该标签加入筛选（用来找该标签的词会从输入里消费掉，含部分输入如「和泉」选「和泉纱雾」，不重复当标题关键词；其余词仍搜标题）；或使用显式 `ns:name` 语法（如 `parody:touhou`）、标签云 / 画廊详情页里的标签。直接回车（不含 `ns:name`）**只做标题文字搜索**，不会被自动识别成标签筛选。
- **多词搜索 = 每词都必须出现**：标题搜索把空格分隔的多个词**逐词 AND**（各自作为独立子串、位置/顺序无关），如 `mimu gif` 命中标题同时含 mimu 与 gif 的画廊；单词与中文整句搜索行为不变。
- **批量加收藏**：勾选后点「批量加收藏」，选 0–9 号夹，分批 25 本提交；**仅云端成功的 gid 写入本地**（加入即从其它夹迁出，EH 一个 gid 只能在一个收藏夹），无 gid 的本地归档会跳过并 toast。
- **批量与筛选删除**：
  - 勾选画廊卡片后顶部显示「批量删除」，可选择是否同步删除磁盘物理文件（**不删盘则进入 `#/recycle`「用户删除」**，可恢复，详见 [库维护](Manage)；部分副本失败时记录与磁盘剩余路径一致）；
  - 支持「删除当前筛选」一键删除当前分类、搜索、阅读状态或标签匹配的全部画廊；后端具有 5000 本安全上限熔断保护（超过返回 409，需缩小筛选范围），分批 500 本安全处理，磁盘只读时会保留 DB 记录并在日志报告。
- **扫描库**触发文件系统扫描：新归档入库，目录里找不到的画廊进入 `#/recycle`「扫描失踪」（可恢复；彻底删除才从索引移除）。扫描完成会发 Telegram 通知；若发现重复副本，消息会附上「N duplicate-copy group(s) found (gid …)」提醒去 [重复副本](Manage) 页处理。扫描在**全局暂停**时不会启动（返回 `paused`）。

## 本地列表（`#/library`）

- **与 ExHentai 解耦**：本地列表完全独立于 ExHentai 云端收藏夹，无 gid 的本地归档（CBZ、目录等）同样可以加入与整理。
- **前端入口与筛选**：入口位于画廊库（`#/library`）与画廊详情页（`#/gallery/<id>`）。画廊库工具栏的列表下拉框可选择特定列表进行筛选过滤（URL 哈希对应 `#/library?list_id=<id>`）。
- **列表生命周期管理**：支持新建、重命名与删除本地列表。在画廊库工具栏可直接点击「新建列表」（输入名称即可创建）；后端 API 提供完整的 CRUD 接口（`POST /api/lists`、`PATCH /api/lists/{id}`、`DELETE /api/lists/{id}`）。
- **画廊归类操作**：画廊库勾选画廊后点击「加入列表」可批量归入（若当前未选列表亦会提示新建并直接加入）；在画廊详情页的列表工具栏可一键点击将当前画廊「加入」或「移出」对应本地列表。

## 标签（`#/tags`）

- 搜索本地标签体系并查看使用次数；用顶部分组筛选（全部 / 标签 / 作者 / 角色 / 原作 / 社团 / 女性 / 男性 / 语言 / 分类）。
- **翻页时顶部的分组筛选条保持不变**。
- 搜索框支持中文补全（与顶栏相同的翻译反向匹配，如输入「巨乳」）；**点选建议留在标签页并过滤标签云**（切到对应命名空间，用英文名检索）。直接提交中文也会按翻译匹配本地已有标签。右侧按钮为「搜索标签」。顶栏搜索仍搜画廊，点选进资料库。
- **点击标签云中的标签**会跳转到画廊库，把该标签**追加**进筛选（多标签 AND 组合）；画廊详情页里的标签同样可追加。
- 中文界面下标签显示翻译；多值标签（`A | B`）只显示翻译的部分（未翻译的英文别名自动隐藏）。
- 结果固定每页 100 条（无页大小选择器；后端 API 上限 500）。

## 历史（`#/history`）

- 按画廊列出阅读历史（最后阅读进度与时间），每项支持一键「开始阅读」直达进度或「✕」标为未读（清除进度并从历史/继续阅读移除）。
- **清空历史**：清空时间线足迹（不影响画廊自身的阅读进度条）。
- **清除阅读进度**：弹窗确认后重置所有画廊的阅读进度（全部标为未读/进度归零）。
- 阅读位置由阅读器自动保存（画廊详情/阅读器进入时自动定位）。
