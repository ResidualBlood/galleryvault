# 浏览与画廊库

> 中文 · [English](Library-EN) | 属于 [使用指南](Usage) 系列

浏览、发现、系列作品、画廊库、本地列表、标签与阅读历史。

## 浏览（`#/browse`）

- **默认首页**：未指定路由时默认进入浏览页，按最新发布倒序展示画廊网格。支持无限滚动加载下一页，底部分页器作为备用；浏览器保存每页显示数量设置。
- **继续阅读**：顶部展示最近阅读的画廊卡片，包含封面缩略图、阅读进度条与百分比。点击卡片继续阅读，点击「✕」标记为未读（重置阅读进度并从继续阅读和历史记录中移除）。
- **工具条**：
  - **命名空间快捷入口**：支持快速筛选标签、作者、角色、原作、社团、女性、男性、语言。
  - **随机画廊**：点击「🎲」按钮随机跳转至一个画廊详情页。
- **键盘操作**：
  - 在任意位置按 `/` 键聚焦顶栏全局搜索框，按回车键跳转画廊库执行标题搜索。
  - 画廊网格支持方向键导航：`←` / `→` / `↑` / `↓` 移动焦点，`Enter` 打开详情页。
- **晚到响应**：切换视图或重新渲染页面后，先前请求晚到的旧响应会被丢弃，不会覆盖当前视图；浏览、标签、画廊详情与阅读器同样适用。

## 发现（`#/discover`）

在线浏览与检索 ExHentai 线上画廊。

- **榜单与视图**：工具栏提供 Popular、Watched 与 Toplist 排行榜（昨日 / 月 / 年 / 总榜，对应原站 `tl=11/12/13/15`）。Watched 在未配置登录信息时显示 Cookie 配置提示。
- **筛选条件**：支持关键词搜索、分类勾选（按原站分类掩码）、最低评分筛选，以及下载画质设置（默认重采样，可选原图）。
- **画廊卡片**：展示封面、标题、分类、页数、评分；角标提示「已入库」、「已收藏」或「未下载」状态。
- **入库与收藏**：
  - 点击下载加入下载队列，详见 [下载任务与管理](Downloads)。
  - 加入收藏可选 0–9 号收藏夹，**仅在云端确认成功后写入本地数据库**。
- **分页与请求规则**：
  - 搜索、Popular 与 Watched 使用站点游标滚动加载下一页。
  - Toplist 固定请求 `https://e-hentai.org/toplist.php?tl=` 并按页码翻页，不跟随设置中的里站基础 URL。
- **状态提示**：区分无结果、Sad Panda、空内容反爬、509 配额耗尽、Cookie 失效、无权限与 IP 封禁，分别给出明确提示，不作为无结果继续请求下一页。

## 系列作品（#/series）

- **自动聚类**：自动识别同人志与漫画系列作品，剥离 C100、COMIC1、例大祭等展会与活动前缀进行聚类展示。
- **分类过滤**：默认仅筛选同人志与漫画分类并分页浏览；点击「显示全部」可切换查看包含其他分类的完整系列。
- **云端作品补全**：聚合展示已加入云端收藏但在本地尚未下载的作品，带有专属角标，支持一键发起批量下载补全本地收藏。
- **手动调整**：支持通过画廊 GID 或收藏夹手动加入系列，将不匹配画廊移出，支持新建组、重命名、删除及在组间调配成员。
- **重新整理**：文件系统扫描完成后自动触发系列重建；亦可在页面手动点击「重新整理」，后台处理进度与结果记录在日志页（`#/logs`）。
- **系列封面**：系列卡片展示对应画廊缩略图封面。

## 画廊库（`#/library`）

画廊库用于浏览与检索本地索引的全部画廊，支持多维排序、状态筛选、标签过滤与批量维护。

### 视图与显示

- **标题显示回退**：全站标题显示模式设为日文时，若画廊日文标题为空或仅为纯数字 GID，展示层自动回退显示英文标题，避免标题空白或仅显示数字。
- **无限滚动与分页**：滚动接近底部时自动加载下一页（默认每页 24 项，可选 5、30、50、100、200、500 项），底部分页器保留作备用。浏览器保存每页显示数量设置，离开后返回仍然保持。加载失败时列表底部出现「点击重试」按钮（按界面语言显示），点击即重试本次加载。
- **封面跳转**：点击画廊封面进入详情页，详见 [画廊详情与阅读](Reading)。

### 排序与状态筛选

| 排序依据 | 说明 |
| :--- | :--- |
| **入库时间（默认）** | 按画廊首次加入本地资料库的时间倒序排列 |
| **发布时间** | 按原站发布时间排列 |
| **标题** | 按画廊标题字母与字典序排列 |
| **页数** | 按画廊总页数升序或降序排列 |
| **体积** | 按画廊文件总大小升序或降序排列 |
| **评分** | 按评分高低排列 |

| 阅读状态 | 筛选范围与判定条件 |
| :--- | :--- |
| **全部** | 显示所有画廊 |
| **未读** | 排除已读完画廊 |
| **在读** | 进度大于 0 且未到末页 |
| **已读完** | 阅读进度达到末页（单页画廊仅有进度 0 时不计入已读完） |

### 高级筛选与保存的搜索

- **高级筛选配置**：次要筛选收纳于可折叠面板中，工具栏显示当前激活的筛选数量。展开后可配置：

| 筛选维度 | 说明与匹配规则 |
| :--- | :--- |
| **页数范围** | 最少 / 最多页数 |
| **最低评分** | ≥2 / ≥3 / ≥4 / ≥4.5 |
| **文件体积** | 最小 / 最大文件体积范围 |
| **发布日期** | 起止发布日期范围 |
| **上传者** | 文本子串模糊匹配（大小写不敏感） |
| **画质** | 原图 / 重采样 |
| **语言** | 快捷筛选匹配对应 `language:` 标签 |
| **本地属性** | 本地星级与本地列表 |
| **不在收藏夹** | 仅显示本地已存在但不在任何 ExHentai 收藏夹中的画廊（含无 GID 的本地归档；已收藏新版本替代的旧画廊归入「更新画廊」；收藏夹未同步过时等价于「全部」） |

- **保存的搜索**：支持将当前组合筛选条件保存为命名搜索（上限约 30 条），可随时在工具栏应用或删除。

### 搜索与标签语法

- **标题搜索**：
  - 直接在搜索框输入文字并回车（不含命名空间语法），对画廊标题执行文字搜索。
  - 空格分隔的多个关键词执行逐词 AND 匹配（各词作为独立子串，顺序与位置无关，例如 `mimu gif` 需同时包含两词）。
- **标签筛选**：
  - **建议添加**：在搜索框输入会显示标签建议，点击建议项加入筛选，已选标签关键词从输入框中扣除。
  - **语法输入**：支持直接输入 `namespace:name` 语法（例如 `parody:touhou`）。
  - **卡片点击**：画廊卡片上的标签支持普通点击加入正向筛选。
  - **组合模式**：标签胶囊栏支持切换 **AND / OR** 模式，仅用于组合正向标签。
- **排除标签**：
  - **语法输入**：输入 `-namespace:name` 或 `-tag`（例如 `-female:lolicon`）。
  - **快捷添加**：使用 Shift / Alt / Ctrl / Cmd + 点击卡片标签可将其作为排除标签加入（不打开详情页）。
  - **生效规则**：排除标签以红色警示样式显示，始终以强制排除形式生效，不受正向 AND/OR 组合模式影响。
- **上传者筛选与匹配**：
  - **标签语法**：输入 `uploader:用户名` 筛选特定上传者，输入 `-uploader:用户名` 排除该上传者。默认匹配模式（`tag_match=exact`）执行精确匹配（优先同大小写，未命中时回退大小写不敏感匹配）；指定 `tag_match=fuzzy` 时对标签名执行子串模糊匹配。
  - **高级筛选字段**：高级筛选面板中的「上传者」输入项对应画廊上传者文本字段，执行大小写不敏感的子串模糊匹配，机制独立于标签筛选；详细补全机制参见 [画廊详情与阅读](Reading)。

### 批量操作与安全限制

- **批量加收藏**：
  1. 勾选画廊卡片后点击「批量加收藏」，选择 0–9 号收藏夹。
  2. 后台按每批 25 本向云端提交。
  3. **限制与安全**：**仅云端确认成功的 GID 写入本地**（移动至新收藏夹，一个 GID 仅能位于一个收藏夹）；无 GID 的本地归档跳过并提示。
- **批量与筛选删除**：
  - **勾选删除**：勾选画廊卡片后可选择是否同步删除磁盘文件。若不删除磁盘文件，画廊移入 [库维护](Manage) 的「回收站 → 用户删除」并可恢复；部分副本删除失败时记录保持与磁盘剩余文件一致；扫描根目录之外的文件跳过整本删除，删除目标就是扫描根目录本身时同样拒绝。批量与危险按钮在请求期间禁用，防止重复提交。
  - **筛选删除**：支持一键删除当前分类、搜索、阅读状态或标签筛选匹配的全部画廊，收藏、已读、已删除（expunged）、媒体类型与存储类型过滤项同样参与匹配。必须带有有效筛选条件，禁止无条件全库清空；单次删除设有 5000 本安全上限（超过时拒绝执行并提示缩小范围），后台分批 500 本处理；磁盘只读时保留数据库记录并在日志报告。匹配数超过 200 本时需二次确认：API 调用须回传 `confirm=true` 且 `match_count` 与当前匹配数一致，否则返回 409；Web 界面会弹出确认框，写明将删除的数量与是否同时删除磁盘文件，确认后自动带上 `confirm` 与 `match_count` 重发。
  - **末页回退**：在最后一页批量或筛选删除后，若当前页超出新的总页数，列表自动回到上一页；上一页仍超出时直接回到末页，不会停留在空页。
- **扫描库**：触发文件系统扫描，新画廊入库，磁盘中缺失的文件移入回收站「扫描失踪」（可恢复，彻底删除后才移出索引）。若扫描根目录离线、不可读、遍历异常，或原本已有画廊的根目录本次未扫到任何候选，本次扫描会跳过「扫描失踪」标记并在日志记录未完成的根目录，避免误把整库移入回收站。扫描完成后发送 Telegram 通知，发现重复副本时提示前往 [库维护](Manage) 处理。系统处于全局暂停状态时不会启动扫描。扫描根会先去重（`/library` 与 `/library/` 视为同一根）；无图片页的 CBZ/RAR/7z 不入库并计入本次扫描的错误数，PDF 需能提取到内嵌图片，纯文字或无内嵌图的 PDF 同样不入库并计入错误数；损坏或加密的压缩包在同一进程内只报错一次，之后扫描静默跳过（不再累加错误数），文件被修复或替换后自动重试，进程重启后会再报一次；历史上经指向根外的符号链接入库的记录会在下一次完整扫描中标记为「扫描失踪」（磁盘文件不动，扫描不完整时不做该标记）；7z 只读包内成员表，不解压整包，页数按全部图片成员计算、页序按自然序；目录型画廊的存储签名包含各页文件名、大小与修改时间，原地改页会被检测并重新入库；旧版本只保存了扫描器签名的记录仍按原逻辑跳过，直到该画廊再次变化。目录名或归档名中的数字前缀需至少 5 位才会被当作 GID。

## 本地列表（`#/library`）

- **独立管理**：本地列表完全独立于 ExHentai 云端收藏夹，无 GID 的本地归档（CBZ、目录等）均可自由归入与管理。
- **入口与筛选**：在画廊库工具栏的列表下拉框中选择指定列表进行筛选（URL 为 `#/library?list_id=<id>`）；亦可在画廊详情页（`#/gallery/<id>`）查看与操作。
- **列表生命周期**：支持新建、重命名与删除本地列表。在画廊库工具栏点击「新建列表」输入名称即可创建。
- **画廊归类**：画廊库勾选画廊后点击「加入列表」批量分配（未选列表时可新建并直接加入）；在画廊详情页可一键加入或移出对应本地列表。

## 标签（`#/tags`）

- **浏览与分类筛选**：检索本地标签体系并查看使用次数；顶部支持按命名空间筛选（全部、标签、作者、角色、原作、社团、女性、男性、语言、分类）。上传者标签亦属于本地标签体系（`namespace="uploader"`），补全规则参见 [画廊详情与阅读](Reading)。翻页时顶部分类筛选条保持固定。
- **搜索与自动补全**：搜索框支持中文自动补全，点选建议后停留在标签页并筛选对应命名空间的标签云；直接提交中文亦通过翻译匹配本地标签。点击「搜索标签」在当前页检索；顶栏搜索框则用于全局搜索画廊并跳转画廊库。
- **标签联动**：点击标签云或详情页中的标签可跳转至画廊库，并将该标签追加至筛选条件（多标签 AND 组合）。
- **语言与分页**：中文界面下标签优先显示翻译，多值标签（`A | B`）仅显示已翻译部分。结果每页固定展示 100 条。

## 历史（`#/history`）

按画廊列出阅读历史（最后阅读位置与时间），每项支持点击「开始阅读」直达进度，或点击「✕」标为未读（清除进度并从历史和继续阅读中移除）。阅读器进入时自动保存与恢复阅读位置。

### 历史与进度清理

| 操作 | 作用范围 | 对画廊阅读进度的影响 | 安全与确认要求 |
| :--- | :--- | :--- | :--- |
| **清空历史** | 清空历史记录中的时间线足迹 | 不改变各画廊本身的阅读进度条 | 弹出确认弹窗，调用必须携带确认参数 |
| **清除阅读进度** | 重置所有画廊的阅读进度 | 全部画廊标记为未读（进度归零），并从继续阅读中移除 | 弹出确认弹窗，调用必须携带确认参数 |
