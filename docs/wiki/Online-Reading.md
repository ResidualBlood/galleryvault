# 在线阅读

> 中文 · [English](Online-Reading-EN) | 属于 [使用指南](Usage) 系列

在线浏览 ExHentai 线上画廊，并在阅读时尽量不占用服务端的 EH 图片额度。

## 在线浏览（`#/online`）

旧链接 `#/discover` 仍会进入同一页面。

- **列表类型**：搜索、热门（Popular）、关注（Watched）与排行（Toplist：昨日 / 本月 / 年度 / 全部）。
- **筛选**：关键词、分类勾选（按原站分类掩码）、最低评分；列表页的默认筛选可在设置中固定。
- **画廊卡片**：封面、标题、分类、页数、评分，角标显示「已在库」「已收藏」「下载中 x/y / 排队中 / 失败」。
- **快捷操作**：桌面悬停、移动端长按打开操作层，可直接阅读、收藏或下载，无需先进入详情页。
- **状态提示**：无结果、需要登录、需要人机验证、IP 被封禁、图片配额耗尽分别给出页内说明与去设置的入口，不会把错误当成空结果继续翻页。

## 在线详情（`#/online/g/<gid>/<token>`）

封面与双标题、分类 / 上传者 / 发布时间 / 页数 / 大小 / 评分，随后是操作行（阅读 · 继续阅读 · 收藏 · 下载）、按 namespace 分组的标签与缩略图。

- 有新版本时提示并可跳转；本机库已有该画廊时显示「打开本机版」。
- 「在官方页打开」在新标签页打开 `{站点}/g/{gid}/{token}/`，使用浏览器自己的 EH 登录态。
- 缩略图按预览页懒加载；点缩略图直接进入对应页。

## 阅读器与两种取图模式

阅读器路由为 `#/online/g/<gid>/<token>/read/<page>`；页码 `0` 表示接着上次的在线进度。

| 模式 | 取图路径 | 服务端开销 | 何时使用 |
| :--- | :--- | :--- | :--- |
| **浏览器直连**（默认） | 后端只解析单页图片地址，`<img>` 由浏览器直接向 H@H 节点取图 | 每页一次轻量解析（走全局 EH 页面并发 6）；**不占服务端图片并发与带宽** | 默认路径；能直连 `*.hath.network` 的网络 |
| **服务器代理**（回退） | 图片经 `…/pages/<n>/image` 由 GalleryVault 代理 | 占用服务端图片并发（12）与图片缓存（默认上限 512 MB） | 本机无法直连 H@H（端口被封、TLS 拦截等）时按设备手动开启 |

- 切换入口：**设置 → 阅读器 → 在线取图通道**（`gv_online_image_mode`，保存在本设备浏览器，不影响其他设备）。
- 并发与预载：解析与代理共用「在线并发」上限（默认 3，设置项 `online_reader_concurrency`）；阅读器最多预载 2 页，翻页不会额外放大解析请求。
- 解析结果只在服务端缓存 10 分钟（H@H 签名有效期 15 分钟）；过期或图片加载失败会重新解析，仍失败时自动换节点重试 2 次。
- 重试仍失败：页内提示「本设备改用服务器代理」与「在官方页打开」，由用户决定，不会静默回退。
- 图片配额耗尽（509 / 429）：暂停预载并提示配额用量，恢复后继续，不会循环请求。
- 在线阅读模式与本地阅读共用同一套排版（单页 LTR / RTL、双页、双页 RTL、条漫）与快捷键，详见 [画廊详情与阅读](Reading)。

## 隐私与网络

- 解析使用服务端已配置的 EH 账号；**浏览器不会带上你的 EH Cookie**，也不会把 Cookie 写入页面或脚本。
- 直连模式下 H@H 节点会看到你浏览器的出口 IP；图片请求不发送 Referer。
- 解析出的图片地址有时效，只用于当前阅读，不写入数据库、阅读历史或导出的文件。
- 代理模式下图片经 GalleryVault 服务端转发，因此**会**占用服务端图片额度与磁盘缓存。
- 伴侣脚本只访问你自己填写的 GalleryVault 地址，不读取、不上传 EH 登录 Cookie。

## 收藏、下载与进度

- **收藏**：可选 0–9 号收藏夹；只有云端确认成功后才把本地状态改为已收藏，失败时保持原状并提示。默认收藏夹可在设置中指定。
- **下载**：一键按默认画质入队，也可在详情页选择重采样 / 原图；下载完成后进入本机库，在线卡片随即显示「已在库」。
- **阅读进度**：在线进度保存在服务端，按画廊（gid + token）记录；「浏览」页顶部提供「在线继续阅读」，历史与继续阅读都只记录页码，不记录图片地址。

## 伴侣脚本（可选增强，零服务端额度）

伴侣脚本在 **E-Hentai / ExHentai 官方画廊页**注入一个面板，提供：

- 库内 / 收藏 / 下载状态（只查你的 GalleryVault 本地库，不触达 EH）；
- 下载到 GalleryVault（重采样 / 原图）；
- 收藏到 GalleryVault（可选收藏夹）；
- 在 GalleryVault 打开该在线画廊。

脚本不实现阅读器，也不复制第三方代码；官方页的阅读增强推荐搭配 [Comic Looms](https://github.com/MapoMagpie/comic-looms)（MIT）。这条路径的 EH 请求全部由你自己的浏览器发出，**不占服务端的任何 EH 额度**。

### 安装

1. 桌面安装 **Tampermonkey** 或 **Violentmonkey**（移动端见下）。
2. 从你的 GalleryVault 实例打开 `/galleryvault-companion.user.js`（构建产物随前端发布），在脚本管理器中新建脚本并粘贴，或直接安装该文件。
3. Chrome / Edge（MV3）需在扩展详情页开启用户脚本权限（Chrome 138+ 为 **Allow User Scripts**，旧版为开发者模式），否则脚本的跨站请求 API 不可用。
4. 先在 **设置 → 账户与安全 → 伴侣脚本 API token** 生成 token：明文只显示一次，请立即复制保存；撤销后使用该 token 的脚本立即失效。
5. 打开任意 EH 画廊页，在面板中填写 GalleryVault 地址与 API token。两者只保存在脚本管理器里，不写入页面、不进日志。

API token 只允许访问脚本需要的接口（会话状态、本地库状态、收藏夹分类、添加 / 移除收藏、创建 / 查询下载任务）；其余接口一律 `403`。脚本不读取 EH Cookie，也不会把 token 渲染进页面。

### 移动端

| 平台 | 可用性 |
| :--- | :--- |
| Android | Firefox for Android（Tampermonkey / Violentmonkey）、Edge for Android（扩展商店安装 Tampermonkey）可用；Kiwi Browser 已停更。 |
| iOS | Safari 需安装 Userscripts / Stay 并在站点上授权；`GM_xmlhttpRequest` 行为与桌面不完全一致。 |

移动端属尽力而为；桌面 Tampermonkey / Violentmonkey 为主要支持路径。
